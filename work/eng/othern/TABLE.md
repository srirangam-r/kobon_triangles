# Even-n table, multiplicity <= 3, FC weights (D = 16, unchanged), exact weight W = n - 1

Method: for each n the window graph is rebuilt with `export_graph_n.py full g.pkl --exactw n-1` (flags of FC), then A30's independent exact-integer
DP `check_w.py g.pkl n-1 work/eng/T25/elim/state_2.pkl 1` is run with the unchanged FC weights (`weights_FC_D16.pkl` = certs[1] of state_2.pkl).
Driver: `run_table_n.sh n` / `run_table_all.sh`; table generated by `make_table.py` from `log_table_dp_n*.log` (n = 14, 16, 20 come from `log_a30dp_FC.log`).
Each n took 1.5 to 3 min wall (export + DP), two jobs in parallel. The g_W*.pkl graphs were deleted afterwards.
Lambda_min = least integer >= n/3 with Lambda = n(n-2) (mod 3); T <= floor((n(n-2) - Lambda_min)/3), from sum_L final + waste = 3 Lambda - n, final >= 0.
Records: only those listed in the repo (SUMMARY.md: 8/15, 10/25, 12/38, 14/54, 16/72, 18/93, 20/117); everything else is marked unknown (not invented).
Tamura = floor(n(n-2)/3), BBL = floor(n(n-7/3)/3), Blanc = floor(n(n-5/2)/3) (even n); BBL and Blanc are theorems for SIMPLE arrangements only.

Reading the table
- Every even n from 6 to 40 passes: DP minimum 32 = 2D, i.e. final >= 0 on every path at W = n - 1.
- The resulting bound beats Tamura for all n (by 1 at n = 6, 8, 10 up to 5 at n = 38) and equals the BBL value floor(n(n-7/3)/3) for every even n 6..40, but now for arrangements WITH triple points.
- Blanc's simple-arrangement bound is 1 or 2 lower than ours at n = 8, 14, 18, 20, 22, 24, 26, ... (it needs strictness beyond final >= 0), so our bound does not reproduce it. It is equal at n = 6, 10, 12, 16.
- The bound meets the record exactly at n = 8, 10, 12, 14, 16, 20 (K(n) for multiplicity <= 3 arrangements). At n = 18 it gives 94 (record 93), the open gap. At n = 6 the bound 7 equals the known value (not listed in the repo).
- The even-n table says nothing about multiplicity >= 4, nor about n > 20 records (unknown to the repo).

Caveats
- Only multiplicity <= 3 (no 4-fold frames); same trust base as work/eng/othern/RESULT.md and FACTS.md (class (a) facts only; celldom load-bearing).
- Only even n (M1 holds for even n >= 4; n = 6 uses the same graph topology, checked by the DP, not separately by data).
- n = 6..12, 18, 22..40 were not data-checked against real arrangements (only n = 14, 16, 20 were, in data_check.log).
