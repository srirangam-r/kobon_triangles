# C44 verdict: Hall condition on a 2-F face

**Verdict: refereed-correct.**

## Class choice

- **At P:** the outer triangles PRX_PR (s1) and PQX_PQ (s5) and the non-cap sector s3 form
  one alternating class. The same holds at R.
- **At Q:** the class holds the outer triangles (q5,q0), (q1,q2) and (q3,q4). Q's single
  block, mutual with P, has middle q5.
- **Hall step.** C38 with |S| = 3 lands at k = 2, which is closed. So there is an extra
  triangle. ✓

## The two cases

- **(i)** A triangle in P's non-cap sector makes r3 and r4 doubly used. A simple far end
  would give an adjacent block, so both far ends are triple. This is a second face, with
  e(P) = 4. The same holds at R.
- **(ii)** A triangle in (q3,q4), together with Q's cap triangle (q4,q5), makes q4 doubly
  used. A simple far end would give a block adjacent to q5, so the far end is triple. This
  is a bridge along m_QR beyond Q. ✓
