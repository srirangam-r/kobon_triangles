# C7 verdict: Lemma C and "t ≥ 7 impossible without …" (work/t3/shared.md)

**Verdict: refereed-fixed.** The two impossibility statements, which are what the ledger
claims, are **correct**. One per-type bound inside Lemma C is **false** and must be
corrected: the bound for bent points. The error does not touch the two stated
conclusions, because bent points are excluded there or cannot exist. It does matter for
the open "mixed bent-pair" analysis, which would use that bound.

## Checked (hand)

**Counting.**
- S = 288 − 3t, since there are no 4-fold points.
- D = Σ_P (b(P) + e(P)/2). By L1 every doubly used segment either is a block middle (one
  simple end) or is a bridge.
- T ≥ 94 ⟺ D − Z ≥ 3t − 6 ⟺ Σ_P c(P) ≥ t − 6 + Z, with c = b + e/2 − 2. ✓

**Types.**
- b ≤ 3.
- Adjacent block middles are impossible: the middle's simple far end would lie on both
  caps.
- b = 2 means an axis (middles opposite) or a bent point (middles at distance 2, with the
  shared ray's first vertex Q on both caps, so [P,Q] is doubly used). ✓

**Axis point.**
- A bridge on a non-axis ray needs its non-cap sector to be a triangle P Q R.
- Its third side is on neither cap. Say ray L− in sector S50: C1 meets B at V_{B+}, and
  C2 meets L at V_{L+}. So a new line M passes through Q and R. Hence Q and R are
  multiple, and PQR is an all-multiple face.
- e ≤ 4, so c ≤ 2, and c ≤ 0 when there is no such face. ✓

**One block:** c = e/2 − 1. **No block:** c = e/2 − 2. **Centroid:** middles 0, 2, 4, the
three shared rays are bridges, so e = 3 exactly and c = 5/2. ✓

**Conclusions.**
- (a) If β = 0, there are no bent or centroid points, so D ≤ 2t and 3T ≤ 288 − t ≤ 281. ✓
- (b) With no bent, centroid, all-multiple face, or point with ≥ 3 bridge ends, every
  c(P) ≤ 0 < 1 ≤ t − 6 + Z. ✓

## The error: bent points

The claim reads: "c(P) ≤ 1/2 without such a cap line, and c(P) ≤ 3/2 with it".

Label P's rays 0..5 with middles 1 and 3, shared ray 2 toward Q, caps C1 ∋ V0, X1, Q and
C2 ∋ Q, X3, V4.
- Ray 0 is a bridge only if S50 is a triangle. Its third side at V0 is not C1, because C1
  meets line(2,5) at Q. So V0 is multiple.
- Likewise ray 4 needs V4 multiple.
- Ray 5 needs S45 and S50, so it needs both V0 and V4 multiple.

Hence e ≤ 2 (c ≤ 1) if only one cap has its second multiple point, and **e ≤ 4, c ≤ 2 if
both do. The value c = 2 is attained.**

**Explicit exact example** (`work/referee4/c7_bent_example.py`).
- Setup: quadrilateral V0 = (0,0), Q = (12,0), V4 = (14,12), V5 = (0,10), and P = (6,5) on
  the diagonal QV5.
- Lines:
  - the four sides: C1: y = 0; C2: 6x − y − 72 = 0; M1: x − 7y + 70 = 0; M2: x = 0;
  - three lines through P: 5x − 6y = 0, 7x − 8y − 2 = 0, 5x + 6y − 60 = 0.
- Result: P is bent (caps C1, C2, middles 1 and 3). All 6 sectors at P are triangles, and
  the rays toward V0, Q, V4, V5 are doubly used bridges. So **b = 2, e = 4, c(P) = 2**.
- Embedded in an exact 18-line arrangement (11 generic far lines added), P still has
  c = 2. The script prints the lines.

**Fix.** For a bent point, c(P) = 1/2 + (#bridges among rays 0, 4, 5)/2, where:
- ray 0 needs V0 multiple;
- ray 4 needs V4 multiple;
- ray 5 needs both.

So c ≤ 1/2 with no second multiple first vertex on a cap, c ≤ 1 with one, and c ≤ 2 with
both.

  max[Σc − (t − 6 + Z)] = −6.

  was built by hand.
