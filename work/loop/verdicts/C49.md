# C49 verdict: an F point with two faces adds two σ gaps

**Verdict: refereed-correct.**

## The claim

- (A1, A5) are consecutive triple points on C0, with X0 simple between them. The same holds
  for (A2, A4) on C3.
- Neither pair is a bridge or a face side, so each adds 1 beyond σ_min. ✓

## Implementation notes (`k5_p11.py`)

**Greedy choice.** For each two-face F point the script picks one of the two matchings
greedily, per point. In general that does not give the global minimum. My version
(`work/referee4/p11_fixed.py`) keeps both matchings and minimises jointly with the bent
gaps, taking the union.
- It gives the **identical 32 rows**, 31 after C47. So the result stands.

**Possible collision.** A C49 pair could coincide with a C45 bent-gap pair only if V lies
on a_P with X0 between P and V. That configuration has an extra σ unit from the pair (P,V)
on a_P, so counting both is safe. The union count I used is conservative anyway.
