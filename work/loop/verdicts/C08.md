# C8 verdict: "k = 4 open pattern = two disjoint consecutive pairs; then Z ≤ 2, claims ≤ 4"

**Verdict: refereed-fixed.**
- The consequence part is correct.
- The characterization is **proved only when there are no doubly used bridges (β = 0)**.
  Nothing written (general.md §5–6) covers k = 4 configurations with β > 0: bent points,
  a centroid, all-multiple triangular faces, or bridges at 0/1-block points. There, the
  per-point accounting does *not* close without further geometry (example below).

**Fixed statement.** Let n = 18 with exactly 4 triple points, no 4-fold points, and
**β = 0**. If T ≥ 94, the configuration is the §6 pattern:
- all four points are type X;
- P1P2 are consecutive on m and P3P4 consecutive on m′, with σ = 2;
- each P_i is killed, with x_P = 1, so x = 4 and D = 8.

Hence Z ≤ 2 and Σκ = 2Z − Z_tr ≤ 4.

**Solver consequence.** The "k4 pattern" restriction (tag `k4 pattern, us ≤ 2, U ≤ 4`) is
sound only for β = 0 instances. The k = 4 instances with a doubly used bridge must stay
unrestricted (apart from the refereed budgets) until the β > 0 case is proved.

## Proof of the fixed statement (referee's write-up)

**Setup.** Use the master inequality 2Λ ≥ n + Φ with Φ = σ + x − 2β + Σh + Cred. A 94
needs Φ ≤ −6. Charge each pair (P, C) in x to P. For a type-X point set
m_P = h_P + x_P + A(P) + L4(P) = −3 + x_P + A(P) + L4(P).

**Every X point has m_P ≥ −2.**
- If P is unkilled, A ≥ 1.
- If P is killed, at least one u is bounded, so some block is in a mutual pair and its cap
  passes through a multiple point: x_P ≥ 1.

**An isolated X point (on no line with another triple point) has m_P ≥ −1.**
- It has no mutual pairs, because a mutual partner is consecutive to P on a line. So it
  is unkilled.
- Its axis carries no other triple point. So L4 applies unless a_P caps a block of some Q.
- If a_P does cap a block of Q, that block cannot be killed. Killing needs a multiple
  V_s on a_P, and that would be P itself, which would have to be consecutive to Q, or a
  second triple point on a_P. Both are impossible for an isolated P.
- So Q keeps m_Q ≥ −2 without the pair (Q, a_P), and that pair can be moved to P.

**Case β = 0 with a non-X point** (a 1-block point has m = x_P ≥ 0; a 0-block point has
m = 3; bent and centroid points need bridges, so none exist):
- Σm ≥ −6, so Φ ≥ σ − 6.
- If σ = 0, every point is isolated, so Φ ≥ −3.
- Otherwise Φ ≥ −5.
- **Closed.**

**Case β = 0, all four points type X:**
- Σm ≥ −8, so σ ≤ 2 is needed.
- σ = 0 is Theorem H.
- σ = 1: two isolated points, so Φ ≥ 1 − 2 − 2 − 1 − 1 = −5.
- σ = 2 with three points on one line and one isolated: Φ ≥ 2 − 6 − 1 = −5.
- σ = 2 with two disjoint pairs:
  - *Non-consecutive pair:* there are no mutual pairs. A −2 point needs its axis to be m
    (R2). The partner's axis is then private, and the partner is at −1, unless m is the
    axis of both. That shared-axis case gains m's parity claim (general.md §2), so each
    pair costs ≥ −3 and Φ ≥ −5.
  - *Consecutive pair:* m is nobody's axis, because the ray toward the partner has a
    multiple first vertex. So −2 means killed with x_P = 1.
- All four points must be at −2, which is exactly the §6 pattern: x = 4, B = 8, β = 0,
  D = 8. Then T ≥ 94 ⟺ Z ≤ D − 6 = 2. ∎

(This uses the shared-axis parity lemma of general.md §2, which I checked only for
plausibility: 15 vertices on m and Σ(m_i + 1) = 9 odd.)

## The gap (β > 0), with what I could settle

These parts I proved:
- **Bent P → Q forces Q to be a 0- or 1-block point.** Q's lines are PQ, C1 and C2.
  - A block of Q with middle Q→X1 would need cap ℓ1 to cross C2 beyond Q, but
    ℓ1 ∩ C2 = V4 lies on the X3 side. The same holds for Q→X3 and for the rays of C1 and
    C2 beyond Q.
  - Only a block whose middle lies on line PQ beyond Q is possible.
  - So Q is never type X, never bent, and bent chains do not exist.
  - This refines Lemma B.
- **A centroid P with k = 4 closes.** The other three points have ≤ 1 block each, σ ≥ 6,
  x ≥ 3 and β = 3. So Φ ≥ 6 + 3 − 6 − 6 = −3.

**Not closed by the table values.** Take:
- P bent toward Q, with a further bridge to R, which is one of P's first vertices V0, V4
  or V5;
- Q a one-block point with bridges to P and R;
- R bent toward Q, or R an X point with bridges;
- S an isolated X point.

Then Φ ≥ σ − 2β + Σm = 3 − 6 − 1 + 0 − 1 − 1 = −6.
- I excluded R bent toward Q (Q would then have to be a 0-block point, giving Φ ≥ −3).
- I excluded R type X via the face PQR (P's sectors next to PQ have simple vertices).
- Other variants, including two bent pairs plus cross bridges (4 − 8 − 2 = −6 in the
  crude count), were **not** checked.

A full k = 4 proof needs this β > 0 analysis written out.
