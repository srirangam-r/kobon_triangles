# C20 verdict: unused first segments at 1-block and bent points (Z_tr credits)

**Verdict: refereed-fixed.** Statements (a) and (b) are correct. **The SAT form for (a) is
unsound as written** and needs an extra premise. C20 is not used by C23–C25.

## Logic

**(a) One-block point, middle r0.**
- A triangle in sector (r1,r2) makes r1's first segment doubly used. With a simple far end
  that is an adjacent-middle block, which is impossible. With a multiple far end it is a
  doubly used bridge, which the hypothesis excludes. The same argument covers (r4,r5).
- Triangles in both (r2,r3) and (r3,r4) would make r3 doubly used. That is a second block,
  impossible for a 1-block point, or a bridge, which is excluded.
- The three-way case split follows. ✓

**(b) Bent point with V0 and V4 simple.**
- A triangle in (4,5) or (5,0) would make ray 4 or ray 0 doubly used with a simple far
  end. That is an adjacent-middle block, which is impossible.
- So ray 5 is unused, or it is a ray. ✓

**Use.** The unused segment has P as a triple endpoint, which gives a distinct Z_tr
incidence at P. ✓

## SAT form (a): missing premise

The premises "a block at P on a toward C" and "no dblbridge on r1, r3, r5" hold at every
**type-X** point. There r3 is the second block middle: it is doubly used, but it is not a
bridge. Yet all six first segments of a type-X point are used and bounded, so the
conclusion fails.

**Fix.** Add "r3's first segment is not doubly used", i.e. ¬(tri over (r2,r3) ∧ tri over
(r3,r4)). That is exactly "P has one block".

(b)'s SAT form is fine. ¬z at V0 and V4 excludes centroids, the other points matched by
the "bent" encoding.

- The SAT form as written, applied to type-X points: **violated in all 34,330 premise
