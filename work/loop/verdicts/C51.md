# C51 verdict: 4-fold split lemma, T′ = T + 2 − t(G)

**Verdict: refereed-fixed.** This is the same wording fix as C35. "Translating d" of a
straight-line arrangement also destroys any other multiple point on d. Use a local
pseudoline move instead, which suffices because every k ≤ 4 closure holds for
pseudolines. Alternatively, rotate d about another multiple point on it.

## Checked by hand

- The coordinate picture (d moved to y = −x − ε):
  - 2 new triangles appear, in s4 and s5;
  - s4 and s5 gain the d-segment;
  - s2 and s7 gain [P, d∩a−] and [P, d∩c−];
  - s3 and s6 only swap their corner;
  - s0 and s1 are untouched.
- The other direction gives the complement. For the line with ray j,
  G_j = {s_{j−1}, s_{j+1}, s_{j+2}, s_{j+4}}. ✓
- **Corollary.** For each line, G ⊔ G′ is all 8 sectors, so min ≤ ⌊t/2⌋. If t ≤ 5 there is
  a split with T′ ≥ T.
- **Iterating the corollary.** New triangles avoid the other multiple points, so their t
  can only fall. ✓
- **Rich residue.** A brute force over the four partitions confirms that when t = 6 with
  every gaining set ≥ 3, the two empty sectors are opposite. The counts of doubly used
  rays and bridges follow.

## Test (`work/referee4/c51_test.py`)

- Data: 1,200 random pseudoline sweeps with 2-, 3- and 4-wire reversals, n = 8–12. They
  contain **1,016 4-fold points**, with t from 1 to 8.
- For each of the 4 lines, both resolutions were built explicitly in the sweep word; each
  removes that line from P and leaves a triple point. That is 4,064 line tests.
- Each gave {T′₁, T′₂} = {T + 2 − t(G_j), T + 2 − t(G′_j)} exactly. **0 failures.**
- The general k-fold statement (k − 2 new triangles, k gaining sectors) was tested only for
  k = 3 (C35) and k = 4.
