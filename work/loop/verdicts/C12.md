# C12 verdict: the k = 4 two-mutual-pairs pattern is impossible

**Verdict: refereed-correct**, given the pattern as characterized.

Together with the fixed C8, this closes **k = 4 with β = 0** completely. k = 4 with a
doubly used bridge (β > 0) is **still open**; see C08.md. So "C8 closed by C12" is right
only for the β = 0 part.

## Logic

**Setup.** In the pattern: B = 8, β = 0, D = 8, S = 276. A 94 needs Z ≤ 2. There are
ℓ = 10 triple lines and 8 non-triple lines.

**Case x ≥ 5.** At most 8 − 5 = 3 blocks have non-triple caps, so clean ≥ 5, 2Z ≥ 5 and
Z ≥ 3. ✓ The fixed C8 also shows that x_P = 2 at any point closes on its own, so in the
pattern x = 4 exactly.

**Case x = 4.** The 4 triple-capped blocks are the mutual ones, capped by b1, b2, b3, b4.
- If m capped any block, it would be of P3 or P4 (a cap avoids its point), and that pair
  would be in x, giving x ≥ 5. So m and m′ are cap lines of nothing. ✓
- At P1 and P2, m is not the axis: the ray toward the consecutive partner has a multiple
  first vertex. So m's entries there are single and opposite by C11's automatic case:
  type X, and no all-multiple face because σ = 2. j = 2 and q = 0.
- By C11, m touches an unused segment at a simple crossing. Likewise m′.
- These touches are made by non-clean lines, so they are distinct from the clean lines'
  touches.
- The other 4 blocks have non-triple caps, so there are at most 4 distinct non-triple caps
  and clean ≥ 4.
- Hence 2Z ≥ Σκ ≥ 4 + 2 = 6 and Z ≥ 3 > 2. ✓ ∎
