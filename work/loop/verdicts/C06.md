# C6 verdict: per-line parity rule — FALSE as stated; FIXED version proved and tested

**Claim (ledger):** a claim-free line has (#triple points on it) + (#cap roles) odd.
(SUMMARY: "a claim-free t-sequence requires (#triple points on the line) + (#parity breaks)
to be odd; breaks occur exactly where the line acts as a cap line".)

**Verdict: refereed-fixed.** The literal rule is false, even on real n = 18 93s. Two
hypotheses are missing, and "#triple points" must be replaced by "#alternating triple
points". The corrected rule below keeps both SUMMARY consequences, which are correct.
**Do not encode the literal rule in the solver: it is unsound.**

## Where the argument breaks

Take a line L with no doubly used segment ("no both entries"). Use the t-sequence
t_0..t_r, with r = 17 − j vertices when n = 18 and there are no 4-fold points. Suppose no
run end next to a zero has a free sign. Each run then satisfies #repeats ≡ length − 1, so
over the whole line **#repeats ≡ m − 1 = 15 − j**. The cap-role part of the claim is right:
at simple crossings, repeats are exactly cap roles (K). The triple-point part is not.

1. **At a triple point Y on L, the pattern (t_{i−1}, t_i) can be same-side or
   alternating.** Label the rays L−, A+, B+, L+, A−, B− and the sectors S01 … S50.
   Suppose every first segment at Y is used and L has no both entries. Then:
   - *same* (s, s) forces the triangles {S01, S23, S45}, the "alternate-sector" 0-block
     pattern. Y counts as a repeat.
   - *alt* (s, −s) forces {S01, S12, S34, S45}. So A is doubly used on both sides of Y:
     Y is a full point and L is a non-axis line through it (or A carries bridges).

   The parity condition is #repeats = K + j_same ≡ 15 − j, that is,
   **K + j_alt ≡ 1 (mod 2)**. It is not K + j ≡ 1. The two agree only when j_same is even.
2. **If a triple point is the first or last vertex of L**, the run next to the virtual
   ray entry ends at a non-simple crossing. The one-sided-line argument (step 5) then does
   not apply, and parity is unconstrained.
3. **If "claim-free" only means κ(L) = 0**, a zero entry next to a triple point is
   allowed: its unused segment has a triple endpoint, so it is Z_tr, not a claim. That
   frees the parity too.

## Counterexamples (all with no both entries on L, and claim-free in the strongest sense)

"Strongest sense": κ(L) = 0, and every bounded segment ending at a multiple point of L is
used.

- **Gallery 93, `gallery/data/18/18-3cg4m0asrnamr.json`, line 16** (T = 93, t = 5).
  - j = 2, K = 0, patterns (alt, end).
  - t-sequence `0+-+-+-+-+-+-+-0`, with vertices `.............TT`.
  - j + K = 2 is even, yet the line claims nothing.
- **Gallery 93, `18/18-18kh1heyvi3hs.json`, line 17** (T = 93, t = 8, Z = 0). It has
  j = 8 and K = 0 (7 alt, 1 end). The same happens in all 17 t = 8 gallery 93s.
- **n = 18, same-side type** (T = 91; `18-1pncjo3pwr97y` with 3 simple triangles
  contracted). Line 16 has j = 2, K = 0, patterns (same, alt), no end point.
  - t-sequence `0-+-+--+-+-+-+-0`, with vertices `.....T.......T.`.
  - The repeat "--" sits at the triple point.
  - Tokens are printed by `python3 work/referee4/c6_find.py 1`.

## Corrected rule (proved above; zero failures in tests)

> Let n be even and L a line with no doubly used segment, no point of multiplicity ≥ 4,
> and simple first and last vertices. Suppose κ(L) = 0 and every bounded segment ending at
> a triple point of L is used. Then **K + j_alt is odd**. Here K is the number of blocks
> capped by L, and j_alt is the number of triple points of L where L's two segments carry
> triangles on opposite sides.

Equivalently: if K + j_alt is even, L touches an unused segment at a simple crossing, or
one of L's triple points is the endpoint of an unused segment (Z_tr credit). A triple point
where L is a non-axis line of a full (type-X) point is always alt and always interior.
Hence:

- *Consequence 1* ("a non-triple line capping two blocks claims") is correct. Here j = 0,
  and no both entries are possible by L1.
- *Consequence 2* ("a line through one full triple point, as a non-axis line, capping one
  block elsewhere, claims") is correct. At a full point all 6 first segments are used, so
  the conclusion is a genuine touch κ(L) ≥ 1.
- The literal "j + K" form is valid exactly when every triple point on L is alt and
  interior, for example when all of them are full points and L is a non-axis line at each.
