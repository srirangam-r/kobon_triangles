# C10 verdict: Lemma A as a local clause

**Verdict: refereed-correct.** There is one wording imprecision; it does not affect the
clause.

## Logic

- **Cap triangles.** tri(a,b,C) and tri(a,c,C) are two distinct faces with the common side
  [P,X] on a, where P = a∩b∩c and X = a∩C. P and X are consecutive, because a face side is
  an edge. Two distinct faces on one edge lie on opposite sides, so [P,X] is doubly used.
  Their sides on C are the edges [C∩b, X] and [X, C∩c], on opposite sides of a. So these
  are the two neighbours of X on C. ✓
- **Extra triangle.** tri(a,C,N) with N ∉ {a,b,c,C} has vertex X. Its side on a cannot be
  [X,P], since that would put N through P. Its side on C is an edge at X, so C∩N is a
  neighbour of X, which gives z(bCN) ∨ z(cCN). ✓
  - This needs no assumption on X. If X is itself a multiple point, the argument is
    unchanged.
- **Consequence.** A triangle over the segment u of a beyond X uses a and C, plus a third
  line N ∉ {b,c}. The triangle on lines a, b, C is the cap triangle on the P side. So an
  extra triangle forces a triple apex. ✓

**Imprecision.** "P's ray along a is a block middle with cap C" and "C touches u at X" need
X to be **simple**. If X is multiple, [P,X] is a doubly used *bridge*, and the unused u
counts in Z_tr, not in κ(C). The SAT clause is valid either way. Any credit taken from it
as a touch must add the premise "X simple", i.e. no z(a,C,·).

Pseudolines: only face/edge incidence is used. ✓
