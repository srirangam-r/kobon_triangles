# A03 verdict: t ≥ 7 residue system and SAT spec

**Verdict: refereed-fixed.** The arithmetic is correct. The SAT spec needs three fixes.

## Arithmetic (checked)

- (R-b)–(R-e) hold, using (R-a) as an inequality.
- **(R-f).** Every point with b ≥ 2 gives a Lemma-A touch or has a cap through a triple
  point:
  - an axis point is killed only via a mutual pair;
  - bent points and centroids have triple caps anyway.
  - Touches are distinct and ≤ 2Z, so #killed ≥ n₂ + n₃ − 2Z. ✓
- **(R-g).** σ ≥ 3t − 18, and j_L ≤ 8.
- **At t = 7:**
  - m ≥ 7, because 3t ≤ C(m,2);
  - Z ≤ 20 − m;
  - at m = 18: B ≥ 12 + Z, n₂ ≥ 5 + Z, and #killed ≥ 5 − Z ≥ 3;
  - 1 + Z ≤ β ≤ 21 − m.
- The example (t = 7, m = 18, Z = 0, B = 12, β = 3) satisfies the whole system. ✓
- Not using C35 is correct, since t = 6 with β ≥ 1 is open.

## SAT-spec fixes

1. **(R-a) / §3.** Use B + β ≥ 3t − 6 + Z, not "=", since the base encodes T ≥ 94. See A01.
2. **§6, the last clause.** "1-block points need e ≥ 3 and 0-block points need e ≥ 5" is
   only a condition *for c > 0*. As a hard constraint it would be **unsound**: a 1-block
   point with e ≤ 2 is allowed, with c ≤ 0. Use it only inside the Σc bookkeeping.
3. **§7 is self-contradictory.** "The line-0 rotation break of C32 (a) 7" *is* "line 0
   avoids every triple point", which §7 then says not to assume, and which is false at
   m = 18. Keep only the χ(0,1,2) (180°) break, or justify a different rotation break.
