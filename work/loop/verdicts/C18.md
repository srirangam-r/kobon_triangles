## (d): the gap

The step "9 − 2μ non-mutual blocks", and with it σ + 2μ ≤ 6, assumes that every mutual
block lies in exactly one mutual pair. **A block can lie in two.**

The "double cross" (`work/referee4/double_cross.py`, exact lines):
- Take a quadrilateral P, V+, P′, V− whose diagonals a (through P, P′) and C (through V±)
  meet at a simple point X.
- Each of the four points has a block with middle toward X.
- Each of those blocks is killed on **both** sides, so it lies in 2 mutual pairs.
- In general this gives #mutual blocks ≤ 2μ, possibly with strict inequality.

**Replacement argument** (in C18's setting):
1. Let x′ be the number of blocks capped by a triple line.
   - Each of the 4 killed type-X points has a killed side.
   - The cap of that block passes through the apex (a partner Q, or R), so it is a triple
     line. Hence x′ ≥ 4.
2. The 3 + σ non-triple lines each cap at least one block, by (b)/(d), and a block has one
   cap. So 3 + σ ≤ 9 − x′, i.e. **σ + x′ ≤ 6**, giving σ ≤ 2.
3. A killed side's apex is consecutive to its point on a shared line. So all 4 type-X
   points lie on shared lines.
   - σ ≤ 2 then forces two lines m and m′ with exactly 2 points each, covering the four
     type-X points.
   - **So R lies on no shared line.**
4. Hence no apex is R, so h = 0. The mutual pairs are exactly (P1,P2) on m and (P3,P4) on
   m′, so μ = 2 and σ = 2. Since x′ ≤ 6 − σ = 4, we get x′ = 4.
   - So each type-X point has exactly one mutual side.
   - Its other side is killed and non-mutual, so it is a ray: the point is 2nd on its axis.
   - The 5 blocks with non-triple caps are capped one each by the 5 non-triple lines. ✓
5. (A double cross would need 6 shared lines, σ ≥ 6, which is impossible here.)

## Consequence: this configuration is impossible

- **m is not a cap line.**
  - Triple-line caps belong only to the 4 mutual blocks, and those are capped by the
    partners' axes.
  - m is nobody's axis: the ray toward the consecutive partner has a multiple first
    vertex, and R ∉ m.
- **m's entries at P1 and P2 are single and opposite.** Both are type X, m is not their
  axis, and a non-cap-sector triangle would make a bridge doubly used, which β = 0 forbids.
- So j + q = 2 + 0 is even, and **by C11 m touches an unused segment. That contradicts
  Z = 0.**
- Equivalently, C18(b) applied to m requires j_m + ρ_m = 2 + 0 to be odd.
- Together with C14, **k = 5 with β = 0 leaves only B = 10 (Z ≤ 1)**.
