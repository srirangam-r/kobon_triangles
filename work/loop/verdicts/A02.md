# A02 verdict: block-cap charging

**Verdict: refereed-correct.**

## Checked

- **Items 1–3.** The three first vertices lie on C, and V_r is simple. A doubly used outer
  ray has a triple far end, since a simple far end would give an adjacent block. So
  (P, C) ∈ x.
- **Item 4.** The ray table matches the adjacency of middles:
  - axis: all four non-middle rays charge;
  - bent: all rays except the back ray;
  - 1-block: the two outer rays;
  - centroid: x = 3.
- **Item 5.** 2x ≥ #charged ends, because a block is charged by at most 2 ends and blocks
  give distinct pairs. So σ + x − 2β ≥ −(#uncharged ends)/2.
- **SAT forms.** The payment clause 2β ≤ σ + 2x + #uncharged is sound, and so is
  blk ∧ dbl → xpair.

## Caution

Item 5 uses x. Do **not** add it on top of per-point m-values that already spend x: the
killed-X, bent, F and O1b bounds all use x pairs. Use one accounting or the other.
