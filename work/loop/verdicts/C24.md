# C24 verdict: k = 4, all-multiple faces with a type-X vertex

**Verdict: refereed-correct.** F1–F3 and every case were re-derived.

## Face-vertex facts

**F1.**
- At an X face vertex P, the rays toward Q and R have multiple first vertices, so the
  middles are on b_P.
- The block covering P→R has its cap through R. At R the outer sector next to R→P is
  bounded by a b_R ray: R's rays go →Q, →P, b_R, …. So the cap is b_R, and likewise b_Q.
- x_P = 2, and both face sides are doubly used.
- A further bridge would sit on r3 or r4. It would need the non-cap sector (r3,r4) to be
  an all-multiple face, which takes 2 more triple points. So e = 2 at k = 4. ✓

**F2** (all three vertices X), using the referee3 argument.
- b_Q is P's cap over rays r4, r5, r0, so it meets line PR beyond P.
- b_Q is also R's cap over R's rays 4, 5, 0, so it meets line PR beyond R.
- b_Q meets line PR only once. Contradiction. ✓

**F3.** The first vertices of R's b_R rays are X_PR and X_QR, both simple.
- Middles at R's away rays would be capped by b_P or b_Q, and those meet the needed ray
  only on the wrong side.
- R's rays toward P and Q have multiple first vertices.
- So R's middles lie in its two b_R rays. Both together would make R type X, excluded by
  F2. Hence R has 1 block with a triple cap (m_R ≥ 1) or none (m_R = 3). ✓

## Cases

**x_f = 2.**
- No bridge R–S: β = 3, σ ≥ 3, Φ ≥ −5.
- Bridge R–S: S lies on line PR or QR beyond R, so σ ≥ 4 and β = 4.
  - S cannot be X, since there is no face SRT.
  - S bent makes R a 0-block point, so Φ ≥ −4.
  - S with one block: Φ ≥ −5.
  - S with no block: Φ ≥ −2. ✓

**x_f = 1.**
- *Q's possible middles are u, opp ρ_P and u′.* Opp ρ_R is impossible, because the cap b_P
  meets line PQ only at P. The only 2-block option is bent toward S, the first vertex of
  opp ρ_R. ✓
- *S without bridges:* Q and R cannot be bent, so Φ ≥ −5.
- *All of SQ, SR, QR are bridges:*
  - S is forced to be b_Q ∩ b_R: S cannot be on line QR or PQ beyond Q and still be
    consecutive with R.
  - Q's blocks then all have triple caps (u by b_P; opp ρ_P by an S-line), and likewise
    R's.
  - σ ≥ 5, β = 5 (K4), Φ ≥ −4 + m_S ≥ −5. If S is X, then x_S = 2 by F1.
- *Other cases:*
  - If S is bent toward Q, Q's block is forced onto u, or Q has none, so m_Q ≥ 1.
  - With [QR] doubly used, C19 at k = 4 gives β_S ≤ 1.
  - An X-type S would need face SQR, which forces [QR] to be doubly used.
  - All of these give ≥ −5. ✓
- *Q bent toward S:*
  - [QR] is singly used: it would be a back-ray bridge (C22), or a bridge triangle through
    a bent point.
  - b_P passes through S, so σ ≥ 5 and β = 3.
  - S is Q's partner, so m_S ≥ 0, and Φ ≥ −3.
  - If R is also bent toward S, then S is a 0-block point by C21. ✓

**No second all-multiple face can hide a case.**
- At P, every sector is either PQR, a cap triangle with a simple vertex, or (r3,r4).
- At R in x_f = 2, both sectors next to R→Q are taken.
