# A01 verdict: bridge-line lemma for t ≥ 7

**Verdict: refereed-fixed** (SAT form only). The mathematics is correct.

## Checked

- β ≤ σ = 3t − m. A bridge is an edge between consecutive triple points, and a line with j
  triple points has j − 1 consecutive pairs.
- The bridge graph is planar with degree ≤ 6. So β ≤ 3t − 6.
- B ≥ m + Z − 6, m + Z ≤ 2t + 6 + C, n₂ + 2n₃ ≥ B − t, and β ≥ t − 6 + Z − C. All follow
  from B + β ≥ 3t − 6 + Z. ✓

## Fix

For T ≥ 94 the D-count is an inequality: **B + β ≥ 3t − 6 + Z**. The SAT form's equality
"B + β = 3t − 6 + Z" holds only at T = 94 exactly. The base encodes ≥ 94 triangles, so the
equality would silently exclude T ≥ 95. Use ≥. All the stated consequences survive with ≥.
