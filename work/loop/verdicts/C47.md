# C47 verdict: (X,X,X,V,O1) is impossible at k = 5

**Verdict: refereed-correct.** The conclusion holds. One step needs an extra sub-case.

## What is correct

- **Survival window.** The filter survives only with i ∈ {0,1}, and the slack is 0 in
  both. The exact σ configurations listed are the only ones.
- **Each extra credit is new:**
  - C11 claims are made by non-cap lines. If the line is a cap, it gives an x pair instead.
  - L4 claims, or x pairs from private axes.
  - Shared-axis claims.
  - None of these is a Lemma-A touch made by a cap line.
- **The shared-axis parity** (general.md §2) is now verified: Σ(m_i + 1) = 17 − 4j holds in
  every overlap case (shared zeros, a point 2nd on its line).

## Gap

"An X with a private axis gives +1" needs that X to be **unkilled**. A private-axis X can
be killed via a mutual partner on the shared line L, if it is 2nd on its axis. The cases
still close:

- **i = 1, L is only X_a's axis.** X_b cannot be mutual with X_a, because that would need
  X_b's cap to be L.
- **i = 1 or 0, L is nobody's axis** (in the two-line i = 0 case, when X_a's axis is
  private). C11 on L applies regardless of any kill.
- **i = 0, three X's on L.** A mutual pair on L needs both members to have private axes.
  - The third X cannot be mutual with either: their other blocks face rays.
  - So the third X is unkilled, and gives +1 via L4 or a new x pair if its axis is private.
  - If its axis is L, C13 applies: j′ = 2, q = 0.
