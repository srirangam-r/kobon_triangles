# C21 verdict: bent points sharing a partner

**Verdict: refereed-correct.**
- Claims 1 and 2 are proved.
- The Claim 3 sub-case is proved. Claim 3's case list omits the second 4-cycle
  (P1Q1, Q1Q2, Q2P2, P2P1). That omission is not an error in C21, which says k = 4 is
  still open; C23 now handles that cycle.

## Logic

**Claim 1.** It uses the C08 fact: if P is bent toward Q, then Q's lines are PQ, C1 and C2,
Q's rays toward X1 and X3 (simple points) are next to Q→P, and any block of Q has its
middle on PQ beyond Q.
- *Adjacent rays:* the first vertex is a simple X, so it is not P2. ✓
- *Alternating rays:* the ray between them carries cap triangles of P1 and P2 on its two
  sides. So it is a block middle of Q off QP1, which the C08 fact forbids. ✓
- *Opposite rays:* collinear with Q between. Q's only possible middle would point at P2,
  which is multiple, so Q has no block. ✓
- *Three bent points toward Q:* impossible. ✓

**Claim 2.**
- Q's other two lines are caps of both P1 and P2. Their first vertices from Q are the
  simple X's, so Q has exactly 2 bridges and is a 0-block point.
- P_i's extra bridges can only go to S.
- If S is type X, it has no bridge. The faces on both sides of [P_i,Q] are P_i's cap
  triangles, with simple X's.
- If S is bent, its partner would have to be Q, giving three bent points toward Q.
- The bounds −3, −4, −1 and "impossible" follow. ✓

**Claim 3, proved sub-case.**
- Q2 lies on a cap of P1, which is a line of Q1, and Q1 lies on a cap of P2. So there is a
  common line M, a cap of both P1 and P2.
- M has exactly one vertex between Q1 and Q2, so X1(P1) = X1(P2) = X.
- The second line through X carries P1 and P2 with X between them, a non-bridge pair.
  So σ ≥ β + 1 and Φ ≥ −5. ✓
