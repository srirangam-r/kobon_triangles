# C9 verdict: budgets "unused simple segments + ℓ ≤ 6+2k" and "claims + 2ℓ ≤ 12+4k"

**Verdict: refereed-fixed.** Both budgets are **true**, for n = 18, T ≥ 94, k triple points
and no 4-fold points. One premise of the stated derivation is **false**: "at most 2 cap
blocks per triple point" fails at centroid-type points, which have 3 blocks. The
intermediate bound D ≤ 2k + σ still holds, but it needs the argument below. The solver
encoding (`us+h`, `U+2h`) is sound.

## Derivation, checked

- Setting: k triple points, no 4-fold points. Then S = 288 − 3k.
- Σ_L j_L = 3k, so σ = Σ_L (j_L − 1)^+ = 3k − ℓ. ✓
- β ≤ σ. A bridge joins two consecutive multiple points of one line, and a line with j_L
  multiple points has j_L − 1 consecutive pairs. ✓
- 3T = S − Z + D. If T ≥ 94 and D ≤ 2k + σ, then Z ≤ 6 + 2k − ℓ. ✓
- Hence us + ℓ ≤ Z + ℓ ≤ 6 + 2k, where us is the number of unused segments with both ends
  simple. ✓
- Also Σκ = 2Z − Z_tr ≤ 12 + 4k − 2ℓ. The number of claims, or of claiming lines, is at
  most Σκ. ✓

## The false premise and the fix

A centroid-type point has b = 3: three blocks whose middles are at rays 0, 2, 4, and
three shared rays that are bridges.
- Exact example: the triangle (0,0), (6,0), (0,6) with its three cevians through (2,2),
  plus 12 far lines (`work/referee4/c9_budget.py`).
- This gives k = 4, with types (centroid, one-block, zero-block, zero-block).

So B ≤ 2k is false. Correct argument for **D = B + β ≤ 2k + σ**:
- B ≤ 2k + c₃, where c₃ is the number of centroid points.
- Each cap C of a centroid P passes through the first vertices Q and R of the two shared
  rays next to its middle ray. [Q,X] and [X,R] are cap-triangle sides, so Q, X, R are
  consecutive on C. So (Q, R) is a consecutive pair of multiple points on C joined by the
  simple point X, and it is *not* a bridge. Each such non-bridge gap gives one unit of
  slack in β ≤ σ = Σ_L (j_L − 1).
- A gap (Q, X, R) is used by at most two centroids: those with a middle ray ending at X,
  one on each side of C along the other line through X. Each centroid has 3 gaps, on its
  3 distinct caps.
- So there are at least 3c₃/2 ≥ c₃ distinct gaps, β ≤ σ − c₃, and D ≤ 2k + σ. ∎

Implicit hypotheses that should be stated:
- no 4-fold or higher points (they change S and D_P);
- no three mutually parallel lines.
