## Addendum (00:30 UTC): one step spelled out

(iv) says "a mutual pair uses 2 blocks, which gives μ = (12 − u)/2". That silently
assumes every mutual block lies in exactly one mutual pair.

**In general this is false.** In the "double cross" (`work/referee4/double_cross.py`, exact
lines), P, V+, P′, V− form a quadrilateral whose diagonals meet at a simple point X. Each of
the four blocks toward X lies in two mutual pairs. What holds in general is
#mutual blocks ≤ 2μ ≤ 2σ.

**Here it cannot happen, so C16 stands.**
1. A block in two mutual pairs forces a full double cross, because the segment beyond X is
   then doubly used. That uses 6 distinct shared lines, a, C, b, c, b′, c′, so σ ≥ 6.
2. By (iii), σ ≤ u ≤ 6. So σ = 6, and these are the only shared lines, each with 2 points.
3. The remaining two triple points then lie on no shared line. But C14 says they are
   killed, and killing needs a partner consecutive on a shared line. Contradiction.
4. So every mutual block is in exactly one pair, and μ = (12 − u)/2 holds as claimed.
