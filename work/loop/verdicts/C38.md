# C38 verdict: C35 rotation fix, and the multi-split (Hall-type) condition

**Verdict: refereed-correct.**

## Rotation fix (for straight lines)

- Rotating ℓ by a tiny angle about the only other triple point Q on ℓ acts near P like a
  translation. It keeps Q, and changes nothing else when ℓ carries no third multiple point.
- At k ≤ 6 such a line exists. If each of P's 3 lines carried 2 further points, that would
  take 6 other points, since each shares at most one line with P, so 7 > 6 in total. ✓
- The pseudoline local split (C35 verdict) remains valid for every k.

## Lemma

- Each split adds its own small triangle Δ_P. A later split at Q never touches Δ_P, because
  Q is not a vertex of Δ_P.
- Faces never lose edges.
- A face is destroyed exactly when it is in the chosen class at one of its split
  vertices. The sector classes at Q are unaffected by earlier splits elsewhere.
- So T′ = T + |S| − |⋃A_P(c_P)|. ✓

## Corollary

If some choice of classes gives |⋃| ≤ |S|, then T′ ≥ T ≥ 94 with k − |S| triple points.
- **k = 5:** every nonempty S is covered, since k ≤ 4 is closed for pseudolines.
- **k = 6:** |S| ≥ 2 is covered, including S = all points, which reduces to Blanc at 0
  triple points.
- **|S| = 2 remark:** the two triangles on [P,Q] are adjacent sectors at P, so they lie in
  different classes. Hence |∩| ≤ 1. ✓
- **SAT consequence:** "≥ 4 chosen-class triangles for 3 points" is sound if the
  triangles are counted distinctly, e.g. ind(f) → tri(f) ∧ (f in the chosen class at some
  point of S).
