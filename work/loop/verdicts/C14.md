# C14 verdict: forced structure for k = 5, 6 without doubly used bridges

**Verdict: refereed-correct.**

## Logic

**Budget.** S = 288 − 3k, and D = B because β = 0. So 94 ⟺ Z ≤ B + 6 − 3k.
- β = 0 excludes bent points (which own the bridge [P,Q]) and centroids (which own 3
  bridges). So b ≤ 2 and every 2-block point is type X.
- k = 6: B = 12 and Z = 0.
- k = 5: B ≥ 9 and Z ≤ B − 9. ✓

**Counting touches.** 2Z ≥ clean + #unkilled. Clean lines touch (L3). Each unkilled
point has a Lemma-A touch by one of its cap lines, which are non-clean, and distinct cap
points give distinct touches.
- Z = 0 ⇒ no clean lines, i.e. every non-triple line is a cap, and no unkilled points.
- A killed block is either unbounded beyond X or mutual. At least one side is bounded.
- So a point with exactly one mutual side is the 2nd or penultimate vertex of its axis. ✓

**The 1-block point R (k = 5, B = 9, Z = 0).**
- A triangle in sector (r1,r2) or (r4,r5) would make r1 or r5 doubly used. That would be
  an adjacent-middle block (impossible) or a bridge (β = 0).
- Triangles in both (r2,r3) and (r3,r4) would make r3 doubly used: a second block, or a
  bridge.
- So r2 or r4 has an unused first segment unless that ray is unbounded. Z = 0 then makes
  R an end vertex. ✓

**Zero defects.** Z = 0 means every segment is used. ✓
