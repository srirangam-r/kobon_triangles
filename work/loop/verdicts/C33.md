## Logic

**Step 1: σ = 3, with exactly two points on each shared line.**
- clean = 0 means all 3 + σ non-triple lines are caps of the 10 − 2μ = 6 non-mutual blocks,
  one or more each. So σ ≤ 3.
- There are three distinct shared lines:
  - a carries U1 and U2.
  - m1 is the U1–K1 mutual line. It is a side line, not a: U1's neighbours on a are the
    simple points X_4 and X_6, so K1 is not consecutive to U1 on a.
  - m2 = a or m2 = m1 would put 3 or more points on one line, giving σ ≥ 4.
- So σ = 3, and each of these lines carries exactly 2 points.
- No double cross is possible, because σ < 6. So the count of 6 non-mutual blocks holds. ✓

**Step 2: m1 and m2 cap nothing.**
- The 6 non-triple lines cap the 6 non-mutual blocks bijectively.
- The 4 mutual blocks are capped by a_{K1}, a, a_{K3} and a_{K2}.
- m2 is none of these:
  - it is a side line of K2 and K3, not their axis;
  - m2 = a_{K1} would put 3 points on m2;
  - m2 = a is excluded by step 1.
- The same reasoning applies to m1. ✓

**Step 3: m2 touches nothing.**
- u₀ = [X_3, X_4] is the only unused segment, and both its endpoints are simple cap
  points, so Z_tr = 0.
- It is touched only by C2 and C1. These cap non-mutual blocks, so they are non-triple
  lines and differ from m2. ✓

**Step 4: C11 on m2 gives a contradiction.**
- m2 carries exactly K2 and K3, both type X with m2 not their axis.
- m2 is not a cap line: by β = 0, a doubly used piece at a simple crossing would be a block
  capped by m2.
- The entries are single and opposite, since β = 0 empties the non-cap sectors. So q = 0.
- Neither point is an end vertex.
- So j + q = 2 is even, and C11 forces κ(m2) ≥ 1, which contradicts step 3. ✓
