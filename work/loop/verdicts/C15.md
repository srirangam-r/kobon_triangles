# C15 verdict: mutual-pair shape, and parity on the mutual line

**Verdict: refereed-fixed.**
- Both general statements over-claim, and each needs one added hypothesis.
- The k = 6 corollary (collinear zigzag impossible) is **correct**, because under C14
  every point is type X.

## 1. Shape statement: "Q has two blocks and is type X with axis a_Q = C" is false in general

- The proof shows only that Q has *a* block with middle Q→X along C, capped by a_P. It
  shows nothing about a second block.
- **Data** (`work/referee4/c13_c15.py`, 13,445 arrangements):
  - 9,125 mutual pairs.
  - The partner Q is a **one-block point in 356 cases**, 284 of them with β = 0 (for
    example the gallery 93 `10/10-1xb9ri5xqq13b.json`).
  - Q is bent in 3 cases, all with β > 0.
- These parts are correct, with 0 failures: Q is consecutive with P on a line m; Q has
  the block at X capped by a_P; the face PQX is a cap triangle of both. If Q is type X,
  its axis is C.

**Fix.** State "Q has a block with middle [Q,X] and cap a_P. If Q has two blocks and β = 0,
Q is type X with a_Q = C." Under C14 (k = 6, β = 0, all type X) the original wording
holds.

## 2. Parity statement: the hypothesis list is incomplete

- As written: β = 0, m not a cap line, no triple point on m has m as axis, and j(m) even,
  imply that m touches.
- This is **false** when m carries a non-type-X triple point. Example: gallery 93
  `18/18-18kh1heyvi3hs.json`, line 17.
  - Its 8 triple points are 7 type X plus 1 one-block point at the end of m.
  - The line satisfies every stated hypothesis and has no touch.
  - In total, 38 n = 18 mutual lines (gallery plus contractions) fail this way; there are
    more at other n.
- The author's own empirical note spots the end-vertex issue, but the statement does not
  exclude it.

**Fix.** Add "every triple point R on m is type X with a_R ≠ m". More generally, use C11's
hypothesis (ii) with j + q even. With that, **0 failures**: every such all-type-X mutual
line touches (7 at n = 18 and 520 in all, n = 8–50 in the gallery run).

## 3. Corollary (k = 6, β = 0)

- C14 gives Z = 0 and all six points type X, so the fixed parity statement applies.
- A mutual line m that is not a cap line, carries no axis, and has j(m) even would touch,
  giving Z ≥ 1. So it is (α) a cap line, (β′) an axis, or (γ) odd j ≥ 3. ✓
- **Collinear zigzag:** m carries all 6 points, so it caps nothing. It is nobody's axis
  (private axes), and j = 6. Hence it is impossible. ✓
