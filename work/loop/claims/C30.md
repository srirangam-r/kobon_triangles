# C30 — k = 5, β = 0, B = 10: Z = 0 is impossible; Z = 1 splits into four rigid sub-cases

**Setting.** n = 18, 5 triple points, no 4-fold point, β = 0, B = 10.
- Every point has 2 blocks; bent and centroid points need bridges, so all points are type X.
- 94 ⇔ Z ≤ B + 6 − 3k = 1.
- There are 3 + σ non-triple lines.
- 2Z = Σκ + Z_tr ≥ clean + #unkilled: a clean line touches (L3), and an unkilled point gives
  a Lemma-A touch by a cap line.

Counting facts:
- A killed point has every bounded axis side mutual, and at least one side bounded.
- Mutual blocks are capped by axes, so non-triple cap lines cap only non-mutual blocks,
  each at least one.
- μ ≤ σ, since mutual pairs are consecutive pairs on shared lines.
- #mutual sides = 2μ.

**(1) Z = 0 is impossible (proven).**
- All points are killed and there are no clean lines.
- u = #points with exactly one mutual side, the other side a ray. Then 2μ = 10 − u, and
  there are u non-mutual blocks.
- All 3 + σ non-triple lines are caps, so 3 + σ ≤ u. Also (10 − u)/2 = μ ≤ σ.
- Hence 16 ≤ 3u, i.e. u ≥ 6 > 5. Contradiction.

**(2) Z = 1 (proven): clean + #unkilled ≤ 2, and 3 + σ − clean ≤ 10 − 2μ.**
- **clean = 2.**
  - All five points are killed, so 2μ ≥ 5, which forces μ = σ = 3. The mutual graph is
    a path P–A–P′ plus an edge Q–Q′.
  - Both clean lines touch the unique unused segment u₀, each at one of its own END
    vertices: a clean line with no zero entry alternates, so it can claim only at X_1 or
    X_17. Write u₀ = [Y1, Y2] ⊂ M, with Y_i an end of the clean line L_i.
  - Z_tr = 0, and 4 singleton ends.
- **clean = 1.**
  - μ = 2 and K = 4 killed points, each with exactly one mutual side (a perfect matching
    Q1Q1′, Q2Q2′), so each is 2nd on its axis.
  - The unkilled point U0 has no mutual side. Its bounded sides are Lemma-A zeros, and
    Z = 1, so it has exactly one of them. It is therefore 2nd on its axis as well.
  - u₀ = [X, Y] is the segment of a_{U0} beyond U0's cap point X, and Y is an END vertex
    of the clean line.
  - 5 singleton ends and 1 touch end.
- **clean = 0, K = 4.**
  - Same shape as clean = 1, with μ = 2.
  - The toucher L_Y at Y is non-clean.
  - Parity of the non-wedge end count (36 = 2·#wedges + 5 + e₀) forces Y to be simple and
    an end vertex of L_Y.
- **clean = 0, K = 3.**
  - The two unkilled points U1 and U2 have their Lemma-A zeros on the same segment u₀
    (Z = 1).
  - So they share the axis a, with u₀ = [X2, X1] between their cap points.
  - Exactly one of them (U1) has its other side mutual. If both did, the killed points
    would need 3 more sides out of 4. If neither did, a would have 6 vertices.
  - Order on a: X_1, U2, X2, X1, U1, X1′, …. So U2 is at position 2, U1 at position 5,
    and u₀ = l_3.
  - μ = 2 with a perfect matching of {U1, K1, K2, K3}.
  - The singleton ends are 4 (K1, K2, K3, U2), and there is no touch end.

**Proof of the touch-end placement.** At a simple end X_1 of L with t_1 single, the other
line's piece on side −t_1 is unused or a ray (C17, Statement 2). So a line end is a wedge, a
cap-point end, or an end at which L touches u₀. u₀ is not the first segment of its line: a
(0,0) pattern at the line end would make two pieces unused. ∎

**SAT form.** For each sub-case, the counts σ, μ, clean, the axis positions above, and
"u₀ unique": exactly one non-triangle consecutive pair, representatives as in C14.

**Empirical.** Not applicable (these are 94s).
