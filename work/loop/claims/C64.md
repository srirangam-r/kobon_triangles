# C64 — a bent point's partner is never a face vertex with both of its face sides doubly used

**Lemma (proven, lines or pseudolines, any k).**
- *Setting.* V is bent toward Q. PQR is an all-multiple face.
- *Claim.* It is not possible that [Q,P] and [Q,R] are both doubly used.

*Refereed inputs* (C35 consequences; C40 Claim 1 = verdict C08):
- V's two cap triangles fill the two sectors of Q next to Q→V.
- Their third vertices are the far ends of V's blocks, so they are simple.
- Q's block middle, if Q has one, is the ray opposite Q→V.

*Proof.* Label Q's rays q0 → P and q1 → R, so the face lies in (q0,q1).
- [Q,P] is doubly used, so (q5,q0) is a triangle. [Q,R] is doubly used, so (q1,q2) is a triangle.
- V ≠ P, R: the face would then flank Q→V with the triple third vertex R or P.
- Let V = first(q_j) with j ∈ {2,3,4,5}.
  - **j = 2.** The flanking triangle (q1,q2) has the third vertex R, which is triple. ✗
  - **j = 5.** The flanking triangle (q5,q0) has the third vertex P. ✗
  - **j = 3.** first(q2) is a simple vertex of V's cap triangle (q2,q3). q2 borders (q1,q2) and (q2,q3), so
    it is doubly used with a simple far end, i.e. a block of Q. But Q's block middle must be opposite q3,
    which is q0. ✗
  - **j = 4.** Symmetric to j = 3: q5 is a block, but the middle must be q1. ✗ ∎
