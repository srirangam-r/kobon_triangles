# C25 — SUMMARY: no 94 with exactly 4 triple points (n = 18, no 4-fold point), all β

**Statement.** An arrangement of 18 lines or pseudolines with exactly four triple points, no
4-fold point, and no three mutually parallel lines has T ≤ 93.

**Case list and the claim that kills each.**

| Case | Claim(s) |
|---|---|
| β = 0: every configuration except the two-mutual-pairs pattern | C8 (refereed-fixed, β = 0 characterization) |
| β = 0: the two-mutual-pairs pattern (P1P2 on m, P3P4 on m′, mutual pairs) | C12 (via C11 parity on m and m′) |
| β > 0, three or more bent points | C21 (≤ 2 bent per partner) |
| β > 0, two bent toward one partner | C21 Claim 2 |
| β > 0, two bent toward different partners, 4-cycle P1Q1Q1P2P2Q2Q2P1 | C21 Claim 3 + C22 (no back-ray bridge) |
| β > 0, two bent, 4-cycle P1Q1Q1Q2Q2P2P2P1 | C23 (all 6 pairs share lines, so σ ≥ 5) |
| β > 0, two bent, β ≤ 3, or a partner with no block | C23 |
| β > 0, one bent point, no X point in an all-multiple face | C23 (uses C19) |
| β > 0, no bent point, no X point in an all-multiple face | C23 (uses Lemma K4) |
| β > 0, all-multiple face with ≥ 1 X vertex | C24 |
| a centroid (3-block) point | verdicts/C08.md |

The ingredients are C10 (Lemma A), C11 (parity), C13, the refereed master inequality
(Φ ≥ −5 ⇒ Λ ≥ 7), Lemma B, and the refereed per-point values.

**Status.** Proposed. It depends on C19–C24, which are not yet refereed. Once those are
confirmed, the k = 4 solver instances can be retired.
