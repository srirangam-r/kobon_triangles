# C47 — (X,X,X,V,O1) is impossible at k = 5

**Setting.** Three plain type-X points X1, X2, X3. A bent point V toward O, which is O1a:
an O1b would need a triple point on V's caps, which raises σ. The only bridge is V–O.
- The filter slack is 0, and it survives only as:
  - (i = 1, σ = 2): one isolated X, and the other two sharing exactly one line L;
  - (i = 0, σ = 3): no isolated X.
- **Any additional credit kills it.**

**Credit sources (all proven or refereed).**
- An X point whose axis carries no other triple point: L4 claim, or its axis caps a block.
  In the second case the x pair is new: V's caps pass through O, O1a has no triple cap, and
  an isolated X cannot be killed through that axis.
- A line carrying exactly two points, neither with it as axis: C11 claim (j = 2, q = 0; the
  entries are single since β = 0 at X points). If it is a cap instead, that is a new x pair.
- A line carrying points that all use it as axis: the shared-axis parity (general.md §2).
  Σ(m_i + 1) = 17 − 4j is odd, so it claims.
  - The Lemma-A zeros exist, because the apexes lie on private lines.
  - A kill through the other X would need a cap through its own point.
- *Note:* the shared-axis parity is proven in general.md; the referee rated it "plausible".

**Proof.**
- **i = 1:** L carries only X_a and X_b.
  - If L is neither's axis, C11 on L gives +1.
  - If L is only X_a's axis, X_b's private axis gives +1 (L4 or new x).
  - If L is the axis of both, the shared-axis claim gives +1.
- **i = 0, three X's on one line L:**
  - An X with a private axis gives +1.
  - Otherwise all three use L as axis, and the shared-axis claim gives +1 (j = 3,
    17 − 12 = 5 odd).
- **i = 0, two 2-point lines:** one of them carries two X's, X_a and X_b.
  - X_a's other lines are private, so X_a has axis L1 (else +1).
  - X_b's axis is L1 (shared-axis claim), L2, or private (L4). All give +1.
  - If the second line pairs an X with V or O, X_b's lines are L1 and two private lines,
    and the same argument applies.

Each case has slack 0 plus one extra credit, so it dies. ∎
