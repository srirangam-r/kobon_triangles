# C37 — k = 5, β ≥ 1 type profiles: pruning leaves 88 type multisets (not rigid)

**Filter.** Script `work/t3/k5_profiles.py`, output in `k5_profiles.out`. It uses only proven or
refereed facts.
- **Types:** X (e = 0), F (type X in all-multiple faces, e ∈ {2,4}), V (bent, e ∈ {1,2,4}),
  C (centroid, e = 3), O1 (e ≥ 1, C35), O0 (e ≥ 2, C35).
- **Bridge graph:**
  - it is K4-free (Lemma K4);
  - its triangles are all-multiple faces;
  - a face has ≤ 2 X-type vertices, and if it has 2, its third vertex is an O-point (C24 F3).
- **Bent points:**
  - each has a partner in O1/O0 (verdict C08);
  - a partner takes ≤ 2 bent points, and 2 only if it is O0 (C21);
  - the partner is not adjacent to the bent point's other bridge neighbours (C19 (b)).
- **D-count:** B + β ≥ 9.
- **Master inequality**, with σ ≥ β + #(non-bridge face sides):
  2β − σ ≥ 2#V + 2#F + 3#O1 + 6#O0 + #X − 9.
  - The #X term is proven: each type-X point either gives a Lemma-A touch (Cred) or is
    killed, which puts a triple cap in x.

**Result.** 88 type multisets survive, as 2,505 labelled bridge graphs. The largest classes
are O1-rich, for example all five points O1 with 6 bridges.
- Hand-deriving rigid structure per profile is not practical.
- The D-count gives **Z ≤ B + β − 9 per profile**, usually 0–4.

**Recommendation.** Add C36 §3 (sound D − Z ≥ 9) and C36 §4 (bent clauses) to k5b before
concluding it is hard; the pilot lacked both. Alternatively, case-split on D = B + β. Each
case then carries the C32-style slack bound Σs ≤ D − 9 on unused simple segments, which is
the kind of constraint the solver finished with at β = 0.
