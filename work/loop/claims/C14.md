# C14 — forced structure for k = 5, 6 triple points without doubly used bridges

**Statement.** n = 18, no 4-fold point, β = 0 (no doubly used segment joins two triple
points). A 94 forces the following.
- **k = 6:**
  - B = 12 and Z = 0.
  - Every point has two disjoint blocks (type X).
  - Every point is *killed*: each bounded axis side is a mutual pair.
  - A point with only one mutual side is the 2nd (or penultimate) vertex of its axis.
  - Every line avoiding the triple points is a cap line.
  - Every consecutive pair on every line is a triangle side (zero defects).
- **k = 5:**
  - B ≥ 9, and Z ≤ B − 9.
  - If B = 10: all points are type X, and clean + #(unkilled points) ≤ 2Z ≤ 2.
  - If B = 9: Z = 0. The four 2-block points are type X and killed, and the 1-block point
    is an end vertex of one of its lines.

**Proof.**
- S = 288 − 3k and D = B. So 94 ⇔ Z ≤ B + 6 − 3k, which gives the B and Z statements.
- A bent pair has a doubly used bridge, so β = 0 rules it out; every 2-block point is type X.
- 2Z ≥ clean + Σ_{unkilled} 1 (L3 plus Lemma A). So Z = 0 gives no clean lines and no
  unkilled points.
- A killed point has each bounded side mutual (C10), and at least one side bounded.
- **The 1-block point R (k = 5, B = 9).** Let R's block be centred at r0.
  - Sectors (r1, r2) and (r4, r5) carry no triangle. Such a triangle would make r1's or r5's
    first segment doubly used, which is a block overlap or a bridge.
  - At most one of (r2, r3) and (r3, r4) is a triangle, else r3 is doubly used.
  - So one of the first segments of r2, r3, r4 is unused unless it is a ray.
  - Z = 0 therefore makes R an end vertex of that line.
- **Zero defects.** Z = 0 means every A(r,i,j) is a triangle side. ∎

**Kills.** It reduces k = 6 (β = 0) to Z = 0 configurations built entirely from mutual pairs;
C15 then prunes these.

**SAT form.**
- k = 6 with β = 0: the clause set A(r,i,j) → tri(r,i,j) for all r,i,j, which is defect
  budget 0. Plus "every line avoiding all z-triples is in some ("cap",L,t)".
- k = 5 with B = 10: budget Z ≤ 1, meaning at most 2 unused (r,i,j) consecutive pairs,
  counting each segment once. Pick representatives by the smallest concurrent label at
  each endpoint.
- β = 0 can be imposed as: for every pair of z-triples t1 ∋ r, t2 ∋ r with their points
  consecutive on r, not both sides of that segment carry a triangle.

**Empirical.** The n = 18, t = 8 gallery 93s have Z = 0. Every 2-block point in them is
type X and killed, consistent with the structure. Nothing in the data contradicts C14.
