# C20 — unused first segments at 1-block and bent points (Z_tr credits)

**Statement (a): 1-block point.** Let P have exactly one block, with middle r0 (covering
r5, r0, r1). Suppose none of the first segments of r1, r3, r5 is a doubly used bridge. Then
the first segment of r2, r3 or r4 is unused or a ray. Precisely:
- if sector (r2,r3) is a triangle, r4's first segment is unused or a ray;
- if sector (r3,r4) is a triangle, r2's is;
- if neither is, all three are.

*Proof.*
- A triangle in (r1,r2) would make r1's first segment doubly used, together with the cap
  triangle in (r0,r1).
  - If its far end is simple, that is a block at r1 overlapping the middle r0. Impossible.
  - Otherwise it is a doubly used bridge on r1, which is excluded.
  - The same argument applies to (r4,r5).
- Triangles in both (r2,r3) and (r3,r4) would make r3 doubly used. That is a second block,
  or a bridge on r3 (excluded). ∎

**Statement (b): bent point** (labels as in C19). If V0 and V4 are simple, the back ray 5's
first segment is unused or a ray.

*Proof.* A triangle in (4,5) or (5,0) would make ray 4 or ray 0 doubly used, since each is
already used by a cap triangle. With V4 or V0 simple, that is a block at 4 or 0 overlapping
a middle. Impossible. ∎

**Use.** Each such unused segment has the triple endpoint P, so it gives Z_tr ≥ 1. That is
+1 in Cred, so the point's m value rises by 1:
- a 1-block point goes from ≥ 0 to ≥ 1;
- a bent point goes from −1 to 0.

The exceptions are exactly "the segment is a ray", i.e. P is an end vertex of that line.
These exceptions are what remain for k = 4, β > 0, together with the bent points whose V0 or
V4 is multiple.

**SAT form.**
- (a) For z[t], t = {a,b,c}, and a block at P on a toward C, with caps as in C10:
  if there is no dblbridge on the three rays r1, r3, r5, then
  OR over r ∈ {r2,r3,r4} of [unused(r) ∨ ray(r)].
  - unused(r): no tri(L_r, x, y) with x ∈ t∖{L_r} and y consecutive beyond P on L_r.
  - ray(r): P is L_r's first (or last) vertex, in the relevant direction.
- (b) Similarly with bent(P→Q) and ¬z at V0 and V4.

**Empirical.**
- (a): 12,032 one-block points without bridges on r1, r3, r5 (gallery plus mutations,
  n = 10–18), 0 failures (`work/t3/c20test.py`).
- (b): no sample had V0 and V4 simple at a bent point, so (b) was not exercised.
