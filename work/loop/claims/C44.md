# C44 — Hall condition on a 2-F face (C38 with S = {P,Q,R}), k = 5

**Setting.** A face PQR with P and R of type X, and Q of type O1b, with Q's block mutual with P
(C42).

**Class choice.** Pick at each vertex the alternating class that contains the outer triangles:
- at P: {PRX_PR, PQX_PQ, P's non-cap sector};
- at R: {RPX_PR, RQX_RQ, R's non-cap sector};
- at Q: {QRX_RQ, PQX_PQ, sector (m_PQ-beyond-Q, m_QR-beyond-Q)}.

The union is {PRX_PR, PQX_PQ, QRX_RQ} ∪ extras, where each extra sits in one of the three
named sectors.

**Hall condition.** C38 needs the union to be ≥ |S| + 1 = 4. The split lands at k = 2, which is
closed. So **at least one extra triangle exists**:
- **(i)** a second face P W1 W2 in P's non-cap sector, with W1 ∈ m_PQ beyond P and
  W2 ∈ m_PR beyond P both triple (so e(P) = 4). Or the same at R;
- **(ii)** a triangle in Q's sector (m_PQ-beyond, m_QR-beyond). It makes m_QR beyond Q doubly
  used, which is a bridge from Q to a point U with R, Q, U consecutive on m_QR.

**Proven.** The pieces used are the refereed class structure (C35), C38 and C42.

**Effect.** As a filter rule ("e(P) = 4, or e(R) = 4, or Q has a bridge besides P and R") it
prunes almost nothing: 20 centroid-free multisets / 70 graphs remain (`work/t3/k5_profiles8.py`).
Case (ii) is geometrically rigid: Q's third bridge must lie on m_QR, collinear with Q and R.
That is not yet encoded.
