# C33 — C32 (d), the k = 5 clean = 0, K = 3 shared-axis configuration, is impossible

**Setting (C30).** k = 5, β = 0, B = 10, Z = 1, clean = 0, K = 3:
- killed points K1, K2, K3;
- unkilled points U1 and U2, sharing the axis a, with X_2 = U2, X_5 = U1 and u₀ = [X_3, X_4];
- mutual pairs U1–K1 (at X_6 = a ∩ a_{K1}) and K2–K3.

**Claim.** This configuration does not exist.

**Proof.**
1. *σ = 3, and each shared line carries exactly two points.*
   - σ ≤ 3, from 3 + σ ≤ #non-mutual blocks = 10 − 2μ = 6.
   - Three distinct shared lines exist:
     - a (through U1 and U2);
     - m1, the mutual line of U1 and K1. It is a side-ray line of both, not a, since a ∩ a_{K1} = X_6 is simple.
     - m2, the mutual line of K2 and K3.
   - Any further triple point on one of them would raise σ above 3. So σ = 3, and m1 and m2 each carry exactly two triple points.
2. *Who caps what.*
   - The 6 non-triple lines are all caps (clean = 0), each capping ≥ 1 of the 6 non-mutual blocks. So they cap those blocks one each.
   - The 4 mutual blocks are capped by axes: a_{K1}, a, a_{K3} and a_{K2}.
   - Hence **m2 caps no block**, and neither does m1 (both are non-axis triple lines).
3. *The only touches.* The only unused segment is u₀. Its endpoints X_3 and X_4 are cap points of U2 and U1, so it is touched only by their caps C2 and C1. These are non-triple lines, so m2 ∉ {C1, C2}.
4. *C11 on m2.*
   - j = 2: it carries K2 and K3, both type X, and m2 is neither one's axis.
   - m2 is not a cap line, by step 2.
   - The entries next to K2 and K3 are single and opposite, so q = 0. This uses β = 0 and Lemma B: the non-cap sectors are empty.
   - Neither point is an end vertex of m2, since type-X points have all rays bounded.
   - So j + q = 2 is even, and **m2 touches an unused segment at a simple crossing**. That contradicts step 3.

The same argument works with m1 in place of m2. ∎

**Consequence.** k = 5, β = 0, B = 10 is closed, assuming C30 and C31 and the solver's 192/192 UNSAT on C32 (c), pending the encoding audit. k = 5, β = 0 is then closed, since B = 9 fell to verdict C18.

**Remark.** This is the same mechanism as verdict C18 (C11 on the mutual line). It may also shorten the C32 (c) sub-cases: in clean ≤ 1, K = 4, the two mutual lines each carry two type-X non-axis points. That could not be closed by hand the same way, because the unused segment's touchers include the touch-end line L_Y. L_Y could be the mutual line m if Y ∈ m, and then m's touch is legitimate. I did not pursue this, since the solver already closed those cubes.
