# C23 — k = 4 with β > 0: closed except all-multiple triangular faces with a type-X vertex

**Setting and tools.** k = 4, no 4-fold point, β ≥ 1. A 94 needs Φ ≤ −6, where
Φ ≥ σ − 2β + Σ_P m_P. The per-point values are:
- bent point: m = −1;
- 1-block point: m ≥ 0;
- 0-block point: m = 3;
- type X: m ≥ −2, and m ≥ −1 if isolated.

These come from verdicts/C08.md. Other facts used:
- σ − 2β = Σ_L (j_L − 1 − 2β_L) ≥ −β. Each shared line adds +1 for each consecutive pair
  on it that is not a doubly used bridge.
- Lemma B: an X point has a doubly used bridge only inside an all-multiple triangular face.
- Bent P→Q forces Q to be a 0- or 1-block point (verdict C08).
- C19: no bridge triangle through a bent point.
- C21: at most two points are bent toward any Q, on opposite sides of Q, and then Q has no
  block.
- C22: a bent point has e ≤ 3 and no back-ray bridge.
- A centroid closes (verdict C08).

**Lemma K4 (proven, lines or pseudolines).** Four triple points cannot have all six pairs
consecutive on common lines. Hence the bridge graph on 4 points has at most 5 edges.
- *Proof.* The six segments are edges of the arrangement, so they are pairwise
  non-crossing and form a planar drawing of K4.
  - Some point, say P4, lies inside the triangle bounded by [P1P2], [P2P3] and [P3P1].
  - The line P1P4 continues beyond P4 inside that triangle. It must leave it, and it cannot
    cross the lines P1P2 or P1P3 again. So it crosses [P2,P3] at an interior point, and P2,
    P3 are not consecutive. ∎

**Claim (proven, modulo the refereed ingredients).** If no all-multiple triangular face has a
type-X vertex, then k = 4 with β > 0 has T ≤ 93. The case list, by v = number of bent points:

- **v ≥ 3:** impossible. Each bent point needs a partner with ≤ 1 block, and C21 allows at
  most 2 bent points per partner.
- **v = 2, both bent toward one Q:** closed by C21 Claim 2 (Φ ≥ −4).
- **v = 2, toward different Q1, Q2** (the four points are P1, P2, Q1, Q2):
  - By C19 the bridge graph is triangle-free, so β ≤ 4.
  - If some Q has no block: Φ ≥ −β − 2 + 3 ≥ −3.
  - If both have one block and β ≤ 3: Φ ≥ −5.
  - If β = 4, the graph is a 4-cycle, and every extra bridge goes to V0 or V4 (C22).
    - Cycle P1Q1, Q1P2, P2Q2, Q2P1: C21 Claim 3 gives σ ≥ β + 1, so Φ ≥ −5.
    - Cycle P1Q1, Q1Q2, Q2P2, P2P1: P2 lies on a cap of P1, which is a line of Q1. P1 lies
      on a cap of P2, which is a line of Q2. So all 6 pairs share lines. At most one line
      carries 3 points (4 collinear would give β ≤ 3), so σ ≥ 5 and Φ ≥ 5 − 8 − 2 = −5.
- **v = 1** (P bent toward Q; R and S not bent). Since there are no X-face points, X
  points are isolated in the bridge graph.
  - *R and S both X:* β = 1, and m_R + m_S + (their σ contributions) ≥ −3, so
    Φ ≥ −2 + 0 − 3 = −5.
  - *Exactly one of R, S is X:* the bridge graph on {P,Q,R} has no triangle through P, so
    β ≤ 2 and Φ ≥ −2 − 1 + 0 + 0 − 2 = −5.
  - *Neither is X:* P's neighbours are independent (C19), so β ≤ 4 and Φ ≥ −5.
- **v = 0:** bridges lie among the w points with ≤ 1 block.
  - w ≤ 1: β = 0.
  - w = 2: Φ ≥ −1 − 4.
  - w = 3: Φ ≥ −3 − 2.
  - w = 4: β ≤ 5 by Lemma K4, so Φ ≥ −5. Any 0-block point adds 3.

In every case Φ ≥ −5, so there is no 94. The C20 credits and the end-vertex exceptions are
**not needed**.

**Open (the only remaining k = 4, β > 0 space).** An all-multiple face PQR with at least one
type-X vertex. Such an X vertex has:
- blocks on its third line;
- both caps passing through the other two face points, so x_P = 2 and m_P ≥ −1;
- e = 2.

Crude counts reach Φ = −6 in the case:
- two X face vertices;
- the third face vertex R has one block;
- S is an isolated X point;
- all three face sides are doubly used.

The likely credit is C20-type: R's away-ray first segment is unused unless R is an end
vertex of line PR. That is the one place the C20 end-vertex exception matters.

**SAT form.**
- "No K4 of consecutive pairs": for any 4 z-triples, not all 6 pairs are consecutive on
  their shared line.
- β ≤ 2 when v = 1 and some X point exists; β ≤ 4 when v = 2.
- The bent constraints from C21 and C22.

**Empirical.** Lemma K4 is a planarity argument (untested). The rest is counting, so it has
no sample test.
