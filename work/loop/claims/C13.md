# C13 — axis lemma through other triple points (R2, even case)

**Statement.**
- *Setting:* n even. P is a triple point with two disjoint blocks, axis a, at position p on a.
- *Hypotheses:*
  - (i) a is not a cap line of any block;
  - (ii) Lemma A is not killed on either side: each of t_{p−2}, t_{p+1} is 0, or is the ray;
  - (iii) every other triple point on a has single, nonzero entries on both sides and is not
    an end vertex of a.
- *Notation:* j′ is the number of other triple points on a, and q the number of those with
  equal signs on both sides.
- **Conclusion: if j′ + q is even, a touches an unused segment at a simple crossing.**
  The case j′ = q = 0 is L4.

**Proof.**
- a has r = n−2−j′ vertices.
- The entries outside {t_{p−2}, …, t_{p+1}} form two stretches bounded by zeros. They have
  m_1 = p−3 and m_2 = r−p−2 inner entries. If p = 2, the first stretch is empty and only the
  second counts.
- If there is no touch, each stretch satisfies m_i ≡ q_i + 1, by the C11 run argument:
  - triple points inside the stretches are alternation or repeat steps, by (iii);
  - rule (d) holds at simple crossings, by (i).
- Adding up: m_1 + m_2 = n−7−j′ ≡ q (mod 2), i.e. j′ + q ≡ 1. For p = 2 the single stretch
  gives n−6−j′ ≡ q + 1, the same condition.
- So j′ + q even forces a touch. ∎

**Kills.** Residual R2 whenever the axis carries an even number of alternating extra
triple points. Example: an axis through exactly one other point Q that is a repeat point
(q = 1).

**Remaining R2.** j′ + q odd, e.g. exactly one other alternating triple point on the axis.
There, the credit must come from σ (the shared line contributes +1 to σ) or from x.

**SAT form.** Same pattern as C11, with the extra antecedent that P = {a,b,c} has two
disjoint blocks with middles on a: tri(a,b,C) ∧ tri(a,c,C) and tri(a,b,C′) ∧ tri(a,c,C′)
for some C, C′ on the two rays. Condition: XOR over the other triples t ∋ a of
(z[t] ∧ ¬rep(a,t)) = 0, plus ok(a,t) for those t, plus a in no cap role, plus the two
C10 non-kill conditions. Then OR_{M,d} U(a,M,d).

**Empirical.** Not yet tested separately. The j′ = 0 case is the tested L4
("valid axis ok", 1,337 cases).
