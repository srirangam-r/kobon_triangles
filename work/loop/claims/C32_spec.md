# C32 — encoding spec for k = 5, β = 0, B = 10 (Z = 1)

Literals as in `search/build_k6z.py` / `kobon_sat.build_defect`:
- `z[t]`, `tri[t]`: sorted triples;
- `A(r,i,j)`;
- `before(r,i,j) = ng[S(r,i,j)] if i<j else pz[S(r,i,j)]`;
- `first(L,R)`, `last(L,R)` (conjunction lists), with `F[L,R]=c17f`, `G[L,R]=c17l`;
- `("cap",L)+t`.

All statements come from C30/C31 (proposed) and the refereed C10, C14, C17 Statement 1, C18, C25.

## (a) Base instance

1. `build_defect(18, 94, 5, alternate=True, exact_triple=True, blanc=True)` + **C10**, unchanged.
2. **β = 0**: the k6z clause, unchanged.
3. **Segment used, with exactly one slack.** For every permutation (r,i,j), extend the k6z C14 clause by a literal `s(r,i,j)`:
   `[-A(r,i,j), tri(r,i,j), usedvia_i…, usedvia_j…, usedvia_ij…, s(r,i,j)]`.
   Then:
   - **Σ_{(r,i,j)} s(r,i,j) = 1.** It is exactly 1, since Z = 0 is impossible (C30 (1)).
   - **s(r,i,j) → ¬z[S(r,i,x)] ∧ ¬z[S(r,j,x)] for all x.** u₀ has two simple endpoints in every sub-case (C30), so exactly one representation (r,i,j) has A true. This also makes the "Σ = 1" count exact.
   - **s(r,i,j) → OR_M before(r,M,i)** and **s(r,i,j) → OR_M before(r,j,M)**. u₀ is not an end segment of its line (C30 proof).
   - **s(r,i,j) → ¬tri(r,i,j)**, plus the negation of every `usedvia` witness. Optional; it only tightens.
4. **Every triple point has two disjoint blocks (type X).** For each triple t, `z[t] →` at least 4 of the tri(x,y,L) with {x,y} ⊂ t and L ∉ t. This is the 4 cap triangles; add it as a cardinality guarded by z[t].
   - **No triple point is a line end:** for L ∈ t and each other line a ∈ t, `z[t] → OR_M before(L,M,a)` and `z[t] → OR_M before(L,a,M)`.
5. **Clean lines.** Replace k6z's "every non-triple line is a cap" by
   `[z[t] for t∋L] + [cap(L,t) for t∌L] + [cl(L)]` with **Σ_L cl(L) ≤ 1**.
   - clean = 2 is dead (C31).
   - In the sub-cases clean = 0 (K = 4 and K = 3), set Σ cl = 0.
6. **Triple-line count:** τ = 15 − σ, with σ ∈ [2,4], so 11 ≤ #triple lines ≤ 13 (c16tl indicators).
   - clean = 0 gives σ ≤ 3, so τ ≥ 12.
7. **C5 / WLOG.** Some line carries two triple points (Theorem H). **Line 0 avoids every triple point and is not the touch line.**
   - This is valid because there are ≥ 3 + σ ≥ 5 non-triple lines, of which the touch line is one.
   - So positions 0 and 18 are always wedges.
   - Keep the χ(0,1,2) symmetry break.

## (b) C17

- **Statement 1** (mutual ends are slope-adjacent): unconditional. Keep as is.
- **Statement 2, weakened for Z = 1.** In k6z the clause is `[-end[L,R], F[R,L], G[R,L]] + both(L,R)`. Add the exception "L touches u₀ at its end":
  `[-end[L,R], F[R,L], G[R,L]] + both(L,R) + [s(R,L,x), s(R,x,L) for all x ∉ {L,R}]`.
  - *Proof.* Suppose L's end X = L∩R is simple and t_1 is single. R's piece at X on side −t_1 borders only a ray face and a non-triangle, so it is unused or a ray.
    - If it is a ray, X is R's end.
    - If it is bounded, it is u₀, which is a consecutive pair of R containing L.
    - t_1 = 0 is impossible: it would leave two unused pieces at X, and R has more than one vertex.
  - Since Σs = 1, this exception fires at ≤ 1 line end (in fact at most one per endpoint of u₀).

## (c) The clean ≤ 1, K = 4 patterns

- **File:** `work/t3/k5_patterns.jsonl`, generated by `work/t3/k5_patterns.py`.
  - It uses your convention (position l = L_l, l + 18 = R_l) and `search/wedge_cubes.wedges`.
  - Positions 0 and 18 are excluded.
  - It gives **32 distinct N and 192 rows**. The 48 of C31 count all positions.
- **Row fields:** `N` (6 non-wedge positions), `t` (touch end), `s0` (U0's singleton), `match` (the two mutual pairs of the other 4 singletons), `wedges`.
- **Per-row units.** Write line(p) = p mod 18, "from p" = first if p < 18 else last.
  - **Wedges** (p,q): `end(p, line(q))` and `end(q, line(p))`, with c17f for positions < 18 and c17l otherwise. These are exactly the wedge_cubes units.
  - **Each singleton p** (line ℓ = line(p)): ℓ's 1st vertex from p is simple, and its 2nd vertex from p is a triple point P with axis ℓ. Literals:
    - ∃C, b<c: `F_p[ℓ,C] ∧ z[S(ℓ,b,c)] ∧ Aₚ(ℓ,C,b) ∧ tri(ℓ,C,b) ∧ tri(ℓ,C,c)`, where Aₚ = A(ℓ,C,b) for p < 18 and A(ℓ,b,C) otherwise.
    - The 3rd vertex from p is simple, of the form ℓ∩D with `tri(ℓ,b,D) ∧ tri(ℓ,c,D)`.
  - **Match pair (p,p′):** line(p) ∩ line(p′) is the 3rd vertex from p on line(p) and the 3rd from p′ on line(p′). In the cube, D = line(p′) above, and symmetrically.
  - **s0 and t** (a = line(s0), L = line(t)):
    - L∩a is L's end at t, i.e. `end(t, a)`;
    - L∩a is a's **4th** vertex from s0: exactly 4 lines, two of them concurrent at the 2nd vertex, cross a strictly before L from the s0 end;
    - the slack sits on a's pair (D, L) or (L, D) in the orientation from s0, where D is the 3rd vertex from s0. That is a unit `s(a, D, L)` or `s(a, L, D)`, depending on the orientation.
  - **clean = 1 vs clean = 0:** these rows cover both. Leave cl free (Σ ≤ 1).

## (d) The clean = 0, K = 3 shared-axis configuration (no end filter)

Existential over the shared axis a and its orientation. Let a's vertices from one end be X_1, X_2, …. Then:
- X_2 = U2 = a∩b2∩c2 is triple: `z[S(a,b2,c2)]`;
- X_5 = U1 = a∩b1∩c1 is triple;
- X_1, X_3, X_4, X_6 are simple, on lines C0, C2, C1, D.
- **Blocks:**
  - `tri(a,C0,b2), tri(a,C0,c2)` (U2's block at X_1);
  - `tri(a,b2,C2), tri(a,c2,C2)` (U2's block at X_3);
  - `tri(a,b1,C1), tri(a,c1,C1)` (U1's block at X_4);
  - `tri(a,b1,D), tri(a,c1,D)` (U1's block at X_6).
- **u₀ = [X_3, X_4]:** the unit slack `s(a,C2,C1)` or `s(a,C1,C2)`, by orientation.
- **Mutual pairs:**
  - D is the axis of a killed point K1, which lies on b1 or c1 and is consecutive with U1 there;
  - there is a face `tri(a, m, D)` with m ∈ {b1,c1};
  - K1's block at X_6 is capped by a: `tri(D,x,a) ∧ tri(D,y,a)` for K1's lines x, y.
  - The other two killed points K2, K3 form a mutual pair and are both 2nd on their axes, with singleton ends.
- **Counts:** Σ cl = 0, σ ∈ {2,3}, μ = 2.
- **Line ends:** 4 singletons (U2's at X_1 of a, and K1's, K2's, K3's). There is no touch end, because u₀'s endpoints are cap points and interior on their caps. All other ends are wedges, and the wedge_cubes u = 4 enumeration applies.
  - C27: K2 and K3 are at cyclic distance ≤ 5.
