# C41 — no centroid at k = 5 (β > 0)

**Claim (proven).** A 94 with exactly 5 triple points and no 4-fold point has no centroid.

**Proof.**
- Let P be a centroid, with arm partners Q0, Q2, Q4 and fifth point R.
- By C40, each Q_i has at most one block, so its type is O1a, O1b or O0.
- **Bridges.**
  - P's bridges are exactly its 3 arms, since r1, r3, r5 are middles with simple far ends.
  - Two Q's share only a triangle side, with a simple cap point X between them, so they are
    not consecutive.
  - So β = 3 + e(R), and R's bridges go only to Q's.
- **σ.** The six lines of the cevian triangle each carry ≥ 2 triple points.
  - Each bridge of R lies on one of its partner's lines, all of which are among those six,
    and distinct bridges lie on distinct lines.
  - So σ ≥ 6 + e(R), which gives **2β − σ ≤ e(R)**.
- **Master condition (C39).** It requires e(R) ≥ cost(R) + Σ_Q cost(Q_i) − 9.
  - Costs: X 1, F 2, V 2, O1a 3, O1b 4, O0 6, C 0.
  - Σ_Q cost ≥ 9, so we need e(R) ≥ cost(R), with e(R) ≤ 3.
- **Every type of R fails:**
  - **R = X:** 0 ≥ 1. Impossible.
  - **R = F:** R's bridges lie in an all-multiple face RST with S, T consecutive. The only
    consecutive pairs are (P, Q_i), so [R, P] would be a 4th bridge of P. Impossible.
  - **R = V:** its partner is some Q_i, which then has two arms. By C40 Claim 2 that makes
    Q_i O0, so Σ_Q ≥ 12, and we would need e(R) ≥ 5 > 4. Impossible.
  - **R = O1a:** e(R) = 1 < 3.
  - **R = O1b:** e(R) ≤ 3 < 4.
  - **R = O0:** e(R) ≤ 3 < 6.
  - **R = C:** its arms go to the Q's, making all three O0. Then Σ_Q = 18, and we would need
    3 ≥ 9. Impossible. ∎

**Consequence.** At k = 5 with β > 0, only the **36 centroid-free multisets / 168 graphs** of
C39 remain. They are mostly F-heavy, e.g. (F,F,F,O1b,O1b).
