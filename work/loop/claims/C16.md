# C16 — k = 6, β = 0: reduction to two rigid sub-patterns

**Setting.** A 94 at n = 18 with 6 triple points, no 4-fold point, and β = 0. By C14 this
means:
- Z = 0 and B = 12;
- all six points are type X and killed;
- every non-triple line is a cap line.

For k = 6, the number of non-triple lines is 18 − τ = σ.

**Notation.**
- ρ_L = number of blocks capped by L.
- j_L = number of triple points on L.
- u = number of points having exactly one mutual axis side (the other side is a ray, so
  the point is the 2nd vertex of its axis).
- μ = number of mutual pairs.

**Claim.**
- (i) Every line L that is nobody's axis has j_L + ρ_L odd.
- (ii) u is even.
- (iii) Every non-triple line caps an odd number of blocks, and all of those are
  non-mutual. So σ ≤ u.
- (iv) μ = (12 − u)/2 ≤ σ.
- Hence **u ∈ {4, 6}**, leaving two sub-patterns:
  - **(A) u = 6:** every point is 2nd on its axis with exactly one mutual side. The six
    points are perfectly matched into μ = 3 mutual pairs, and 3 ≤ σ ≤ 6.
  - **(B) u = 4:** μ = 4 and σ = 4. There are exactly 4 non-triple lines, each capping
    exactly one block (a non-mutual one). Every consecutive pair of triple points on a
    shared line is a mutual pair.

**Proof.**
- *Line ends.* Type-X points have first vertices on all six rays, so no triple point is
  an end vertex. Every line end X_1 is therefore simple. Consider its entry t_1:
  - *t_1 single.* The piece of the other line R_1 on side −t_1 borders only the ray face
    and a non-triangle, so it is unused. Z = 0 then makes it a ray, so X_1 is also an end
    vertex of R_1 (a **mutual end**), and R_1 lies on side t_1.
  - *t_1 = "both".* l_1 is a block middle, since β = 0. So L = a_P, X_2 = P, and X_1 is P's
    cap point. That cap point is interior on its cap line (neighbours V_±).
  - Counting the 36 line-ends: 36 = 2·#(mutual end points) + #(cap-point ends), and the
    cap-point ends are exactly the unbounded axis sides. This gives **(ii)**.
- *(i).* Let L be nobody's axis.
  - Its end entries are single, so both ends are mutual ends.
  - R_1 and R_r are one-sided on sides t_1 and t_{r−1}. Their intersection is off L, so
    t_1 = t_{r−1}.
  - All 16 − j_L entries are single, since Z = 0 and there is no "both" on a non-axis line
    when β = 0.
  - Consecutive entries repeat exactly at the ρ_L cap points of L. A repeat at a simple
    crossing forces a doubly used piece ending at a triple point, which is a block capped
    by L. Entries alternate at L's triple points (type X, β = 0, Lemma B).
  - So 15 − j_L − ρ_L sign changes is even, i.e. j_L + ρ_L is odd.
- *(iii).* A non-triple line has j = 0, so (i) gives ρ odd, in particular ≥ 1.
  - Mutual blocks are capped by axes, which are triple lines, so non-triple lines cap only
    the u non-mutual blocks.
  - Hence σ ≤ u.
- *(iv).*
  - A mutual pair uses 2 blocks, which gives μ = (12 − u)/2.
  - A mutual pair is a consecutive pair on its shared line (C15). One pair of points P, Q
    gives at most one mutual pair, since X = a_P ∩ a_Q.
  - So μ ≤ Σ_L (j_L − 1) = σ.
- *Combining:* 12 − u ≤ 2σ ≤ 2u, so u ≥ 4, and u ≤ 6 is even. ∎

**Kills.** All k = 6, β = 0 configurations except sub-patterns (A) and (B).

**SAT form (additions to work/k6z).**
- **End-pairing:** for every line L and every other line R, if L∩R is L's first (last)
  vertex and L's first segment is singly used, then L∩R is also an end vertex of R. In
  chi: "no other line's crossing precedes (follows) it on L" implies "no crossing precedes
  (follows) it on R, in one of the two directions".
- **Parity (i):** for each L that is in no axis role, XOR over the 17 − j_L entries of
  "repeat" = 1 + j_L (mod 2). Equivalently, XOR_t z[t ∋ L] ⊕ XOR_{t∌L} cap(L,t) = 1. Here
  cap(L,t) := z[t] ∧ (L caps a block of t) is two-sided: at least 2 tri of L with pairs
  from t.
- **Cardinalities:** Σ_{L non-triple} 1 ≤ #(points with an unbounded axis side); u ∈ {4,6}.

**Empirical.** Not testable directly, since these are 94s. Ingredient (i) is the
Z = 0 / β = 0 specialisation of C11 and C6, which were tested.
