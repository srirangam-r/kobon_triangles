# C38 — multi-split (Hall-type) condition, and a fix to C35's proof

**Fix to C35 (proof detail).**
- If P's translated line ℓ carries another triple point Q, translating ℓ also splits Q.
  The fix is to rotate ℓ by a tiny angle about Q instead: locally at P this is a
  translation, and Q is kept.
- This needs a line of P carrying at most one other triple point. **At k ≤ 6 such a line
  always exists**: if all three of P's lines carried two others, that would need 6 other
  points, since each shares at most one line with P.

**Lemma C38 (proven).**
- *Setting.* Take k ≤ 6 and no 4-fold point. For a triple point P and a class
  c ∈ {even, odd}, let A_P(c) be the set of triangles in P's sectors of class c.
- *Claim.* For any set S of triple points and any class choice (c_P)_{P ∈ S}, splitting the
  points of S one by one gives an arrangement with k − |S| triple points and
  **T′ = T + |S| − |⋃_{P∈S} A_P(c_P)|**.
- *Proof.*
  - Each split creates one new triangle. A triangle is destroyed exactly when it lies in
    a chosen class at at least one of its split vertices, since it gains an edge there.
    Faces never lose edges.
  - Each step uses the C35 split, rotated as in the fix, in the current arrangement.
    Later splits see the same faces, with possibly extra edges.
- *Tested.* 720/720 random splits of 2–3 points (gallery n = 16–20) matched the formula
  exactly (`work/t3/multisplit_test.py`).

**Corollary (Hall-type condition).** In a 94 with k triple points: for every S such that no
94 exists with k − |S| triple points, and every class choice,
**|⋃_{P∈S} A_P(c_P)| ≥ |S| + 1.**
- **k = 5:** this holds for every nonempty S, since k ≤ 4 is closed.
- **k = 6:** it holds for every S with |S| ≥ 2 now, and for |S| = 1 once k = 5 is closed.
  So at k = 6, **the condition for all pairs, triples, …, and for S = all six points
  holds already**, independently of k = 5.

**Remarks.**
- |S| = 1 is C35.
- |S| = 2 is implied by C35. Two triangles containing both P and Q are the two triangles
  on the segment [P,Q], and they lie in different classes at P.
- The strong cases are |S| ≥ 3, especially S = all points in sparse configurations. The
  condition then reads: **no choice of classes makes all chosen triangles fit into k
  triangles.**
- I have **not** yet derived an #O1 bound from it.

**SAT form.**
- For S = all k points: introduce class-choice-free "hitting" auxiliaries. For each
  triangle tri(u,v,w), define hit(u,v,w) ⇐ (it lies in the chosen class at some vertex).
  The instance with chosen classes as free variables, and Σ hit ≤ k, must be UNSAT for
  every choice.
- That is a ∀∃ condition, so it is not directly SAT-encodable.
- Encode only as cheap consequences, for example: for every 3 z-triples pairwise sharing
  lines, and every class choice (8 choices), the union of chosen-class triangles is ≥ 4.
