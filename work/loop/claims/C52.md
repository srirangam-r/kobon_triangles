# C52 — rich 4-fold points: structure and the D-count and master-inequality costs (partial)

**Structure (proven).** Let P be a rich 4-fold point (C51: every gaining set has ≥ 3
triangles), and let t = t(P).
- **Doubly used rays.** A ray is doubly used iff both neighbouring sectors are triangles.
  - t = 8: all 8 rays are doubly used.
  - t = 7: 6 rays are doubly used.
  - t = 6: the two empty sectors are opposite, which leaves 4 doubly used rays in two
    adjacent pairs.
- **Middles and bridges.** Two adjacent middles (simple far ends) share their cap, since the
  far end X of one is simple and lies on the other's cap. A cap spans at most 4 rays, so
  middles come in runs of length ≤ 2 separated by bridge rays (multiple far ends).
  - t = 8: D_P ≤ 5 and e_P ≥ 3.
  - t = 7: D_P ≤ 4 and e_P ≥ 2.
  - t = 6: at most D_P = 4, with e_P = 0. This is the *standard* 4-fold point with two full
    caps and two axes; blocks (middles) are exactly the doubly used rays.
- **Consequence:** the standard point is rich. So C51 alone does not remove 4-fold points.

**D-count (Σ_P (D_P + e_P/2 − c_P) ≥ Z − 6).** Contribution of P:
- t = 8: ≤ −1.5;
- t = 7: ≤ −3;
- t = 6: ≤ −4.

Triple points contribute ≤ 1.5 each (centroid), ≤ 1 (bent or two-face X), and ≤ 0 otherwise.

**Master inequality (Φ ≥ σ − 2β + Σ m_P).**
- For the standard point: h_P = 16 − 8 − 4 − 2 = 2. Each of its two axes has both rays
  doubly used, so each gives ≥ 1 Lemma-A touch unless killed (C10 holds verbatim at k = 4).
  So m_P ≥ 4 when unkilled, and ≥ 2 + x_P otherwise.
- For comparison: a type-X triple point has m ≥ −2.
- **So a standard 4-fold point is worth at least a triple point.** Replacing it by a triple
  point costs Φ at most 4 − (−2) = 6 but frees S by 5. The exact budget is still to be done.

**Not closed.** "No rich 4-fold point" is not proven. The dangerous cases are:
- bridge-rich t = 7, 8 points, which need ≥ 2–3 multiple neighbours;
- mixtures of standard 4-fold points with many triple points.

## Per-point master values with the bridge charge (round 27, proven)

Charge each bridge −1/2 to each endpoint, using σ ≥ β. Then m′_P = h_P + x_P − e_P/2, where
h = 12 − 2D − caps for k = 4.
- **t = 8:**
  - D = 5 (runs MM, MM, M): 3 caps, each through a multiple span-end point, so x ≥ 3.
    h + x ≥ 2 and e = 3, so **m′ ≥ 0.5**.
  - D = 4 (MMBBMMBB or MBMBMBMB): h + x ≥ 4 and e = 4, so m′ ≥ 2.
  - D ≤ 3: m′ ≥ 3.5.
- **t = 7:** D ≤ 4 and e ≥ 2, so m′ ≥ 1.
- **t = 6 (standard):** m′ ≥ 2, plus up to 2 Lemma-A touches.

For comparison, triple points have:
- m′ ≥ −2 (plain X);
- −1 − e/2 (bent);
- −4.5 (centroid);
- −e/2 (O1);
- 3 − e/2 (O0).

**Consequence (proven).**
- In a 94 (Φ ≤ −6), every rich 4-fold point contributes ≥ +0.5.
- So the triple points must supply Σ_triple m′ ≤ −6 − 0.5·#rich, even more than without
  4-fold points.
- The rest of the charge is carried by triple points alone. Non-rich 4-fold points are
  reduced to triple points by C51.
