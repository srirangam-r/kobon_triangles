# C34 — β > 0 toolkit for k ≥ 5: the D-count, which points can be positive, bent partners

Notation (C07): for each triple point P, b(P) is its number of blocks and e(P) its number
of doubly used bridge ends. Set c(P) = b(P) + e(P)/2 − 2. The claims hold for any k, with no
4-fold point, at n = 18.

**(a) D-count (refereed in C07).** T ≥ 94 ⟺ Σ_P c(P) ≥ k − 6 + Z.
- k = 5 needs Σc ≥ Z − 1.
- k = 6 needs Σc ≥ Z ≥ 0.

**SAT form (redundant, but cheap and exact).** Z − D ≤ 6 − 3k. For each consecutive pair,
define:
- used2(r,i,j): a triangle on each side, which only happens at a triple endpoint;
- unused(r,i,j): the C32 slack.

Count one representative per segment: choose the smallest concurrent label at each endpoint.
Then Σ unused − Σ used2 ≤ 6 − 3k.

**(b) Which points can have c(P) > 0 (proven from refereed pieces).**
- **Type X:** c = e/2. It is positive only in all-multiple faces, one or two of them, with
  e = 2 per face (Lemma B). So c ≤ 2.
  - A face has at most 2 X vertices (the 6-lines / 7-bounded-faces argument of C4 note (b)
    is k-independent).
  - If a face has 2 X vertices, the third vertex has at most 1 block, on its third line,
    with a triple cap (C24 F3; the proof is k-independent). So its c ≤ 1 + e/2 − 2.
- **Bent:** c = 1/2 + (#extra bridges)/2 (verdict C07 fix).
  - An extra bridge on ray 0 or ray 4 needs V0 or V4 triple.
  - Bridges to both V0 and V4 force ray 5 to be doubly used with V5 triple (verdict C19
    fix; otherwise P is a centroid).
  - So c ∈ {1/2, 1, 2}, and c = 2 only with Q, V0, V4, V5 all triple, i.e. k ≥ 5.
- **1-block:** c = e/2 − 1, positive only when e ≥ 3.
- **0-block:** c = e/2 − 2, positive only when e ≥ 5.
- **Centroid** (3 blocks, 3 bridge ends): c = 5/2. It needs 3 triple first vertices.

**(c) Bent partners (proven, k-independent).**
- Bent P → Q forces Q to have 0 or 1 blocks, with Q's block middle on line PQ beyond Q
  (verdict C08).
- At most two points are bent toward Q, on opposite sides of Q, and then Q has no block
  (C21 Claim 1; its proof never uses k).
- Consequence: charge each bent point P with half of its partner's c when Q receives two
  bent points, and all of it when Q receives one. With e(Q) counting the bent bridges:
  - Q 1-block with one bent point: c(P) + c(Q) ≤ 2 + (e(Q)/2 − 1). The bent bridge
    contributes 1/2 to e(Q)/2.
  - Q blockless with two bent points: c(P1) + c(P2) + c(Q) ≤ 4 + e(Q)/2 − 2.

**Where this leaves k = 5, 6 with β > 0 (not closed).**
- The D-count alone does not close either value of k.
- Closing needs the claims side as well, i.e. the master inequality with Z lower bounds:
  clean lines, Lemma-A touches, and C20.
- The k = 4 route (C23/C24) fails at two points:
  - C19's "no bridge triangle through a bent point" is false for k ≥ 5;
  - bent points can have e up to 4.
- **Proposed solver route.** Add (a) as an exact cardinality constraint, the C21/C19-fix bent
  clauses and C10 to the k = 5 and k = 6 instances with "≥ 1 doubly used bridge". Let the
  solver find the residue, and I will characterize whatever survives.

**Empirical.** The pieces were tested by the verifier (C07 fix, C19 fix: 10,000 contracted
arrangements, 0 failures). (b) and (c) as stated here are not separately tested.
