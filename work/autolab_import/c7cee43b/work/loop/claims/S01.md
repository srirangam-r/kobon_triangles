# S01. End-circle symmetries and optional prefix lex leaders

**Status: proposed; independent referee review required.** Engineering claim,
not a new upper bound or a closure of any triple-point case. The submitted
arrangement is unchanged.

## Domain and action

Use the slope-labelled, pairwise-intersecting affine arrangements of
`search/kobon_sat.py`, with the three-valued sign returned by
`chi3_from_lines`. Vertical lines can be removed by a coordinate rotation;
parallel lines are outside this SAT model. No claim here removes parallels
while preserving bounded faces. Concurrency is allowed.

The oriented end circle is `L0,...,L(n-1),R0,...,R(n-1)`. In
`search/symmetry.py`, a parameter tuple `(s,o,h)` has start `0 <= s < 2n`,
orientation `o in {+1,-1}`, and mirror `h in {0,1}`. New line i corresponds to
end

    e_i = s + (-1)^h i + n [o=-1]   (mod 2n).

Its old line label is `p_i = e_i mod n` and its end is reversed iff `e_i >= n`.
The 8n parameter tuples contain a redundancy: `(s,-1,h)` equals
`(s+n,+1,h)`. There are 4n distinct end-circle actions, possibly nonfaithful on
very small chi arrays. For sorted `t=(i,j,k)`, let `u=sort(p_i,p_j,p_k)`,
let `I` count inversions of that unsorted triple, and let `F` count its reversed
ends. Then the implemented action is

    (g chi)[t] = (-1)^(I+F) chi[u].

**Derivation.** For increasing slopes, chi is the sign of the determinant of
normalized line rows `(m,-1,q)`. A new start reverses the normalization of
precisely the wrapped lines, giving F sign changes; sorting the rows gives I.
For the base mirror `y -> -y`, the coordinate determinant changes sign and
normalizing all three line rows changes sign again: these cancel. Thus there
is no additional mirror factor. The base mirror reverses labels, so its
inversion sign is still present. Composing starts, half-turns, and this mirror
gives the formula. A half-turn has `p_i=i` and reverses three ends, hence
`g chi=-chi`.

Every start is realizable by a nonsingular orientation-preserving affine map:
for a slope gap h, use `x'=y-h*x, y'=-x`. It moves slopes below h to the end
and reverses exactly those lines' oriented ends. The second half of the starts
adds the half-turn. Together with reflection these are affine bijections, so
they preserve bounded triangular faces and all point multiplicities. The
same relabelling acts on pseudoline arrangements by choosing a new end cut
and reversing the wiring when necessary. This is the end-circle action of
`work/loop/verdicts/AUDIT_k6z.md`, section 1; it is not arbitrary reorientation
of an oriented matroid (which could change the affine chart).

## Compatibility with existing breaks

Order the three values as **0 < +1 < -1**, and order triples lexicographically.
Choose any orbit minimum for this word. Its first sign cannot be -1: the
half-turn would make it +1 and yield a smaller word. Thus a minimum also
satisfies the existing `chi(0,1,2) != -1` break, including when the sign is zero.
A minimum of the full word satisfies every prefix comparison.

**Line 0 off triple points is conditional**, not a universal WLOG: an
arrangement in which every line contains a triple point has no such labelling.
If a separate argument establishes an eligible line and the caller selects it
as line 0, use only the subgroup with `p_0=0`, i.e. `s mod n = 0`. It contains
four distinct end-circle actions, including the half-turn, and preserves both
"line 0 off triple points" and "line 0 defect-free". Every orbit of an already
eligible arrangement under this subgroup therefore has a minimum satisfying
both breaks. No comparisons against rotations moving line 0 are added.
This conservative stabilizer loses some possible pruning but not coverage.
The zero-sign break alone need not be invariant under the subgroup: the
minimum argument establishes compatibility directly.

`build_defect(..., lex_prefix=K)` automatically uses this subgroup if its
legacy defect-budget or case rules anchor line 0; otherwise it uses the full
group. A caller adding an anchored condition later **must** pass
`lex_fixed_line0=True`, or call `add_lex_leaders` afterwards (its default is
conservative). Other labelled assumptions, e.g. distinguished points or fixed
cubes, require a separate stabilizer/coverage argument. Full-group lex leaders
are not automatically sound with arbitrary existing cubes.

## Exact clauses

Let `X[t,v]` be the existing one-hot literals `z, pz, ng`. The transformed
literal for value v at t is `Y[t,v]=X[u,(-1)^(I+F)v]`. For each g and each
of the first K sorted triples, let E be equality of the preceding prefixes
(initially true). For each ordered value pair `v>w`, append

    not E OR not X[t,v] OR not Y[t,w].

Except at the final triple, create E' and encode **equivalence**
`E' <-> E AND (X[t]=Y[t])` using

    not E' OR E                         (omit for first triple)
    not E' OR not X[t,v] OR Y[t,v]       (each v)
    not E  OR not X[t,v] OR not Y[t,v] OR E'   (each v).

One-hotness proves equivalence: E' forces equality, and a matching true value
with E forces E'. Thus the clauses are exactly a prefix lex comparison, not
an approximation. The finite-orbit minimum proves simultaneous satisfiability
for at least one labelling of every eligible geometric/pseudoline orbit.
All fresh variables are reserved above **both** the base CNF header and the
shared IDPool top; subsequent callers must continue that pool or start above
the updated CNF header. K=0 appends nothing. Existing default builds are
unchanged. Size is O(|G|K), at most 10K-7 clauses and K-1 variables per
nonidentity comparison (duplicate or tautological clauses are harmless).

## Reproduction and scope of tests

    uv run --no-project --with 'python-sat==1.8.dev24' python search/test_symmetry.py
    uv run --no-project --with 'python-sat==1.8.dev24' python search/kobon_sat.py 7 0 --defect 1 --lex-prefix 12 --dimacs /tmp/symmetry.cnf

The test uses `chi3_from_lines` on independently transformed rational lines,
checking the label/sign formula for all 8n parameter choices. It checks face
support sets using the repository's existing `count_general` helper solely
for invariance, and point multiplicities by unions of concurrent intersection
pairs. These are regression checks, not official scores. It discovers
`submissions/*/solution.json` and `work/certs/*/solution.json`; the latter
directory is absent at this base commit and is explicitly reported. Added
fixtures exercise zeros, a fourfold point, and a pencil (where the line-0
WLOG must not be imposed).

Exhaustive one-hot clause tests at n=4 include all 81 sign assignments,
not just realizable ones, with prefixes 0,1,4 and both group modes; actual SAT
answers must equal the reference lex predicate (486 checks). Fresh-ID
collision and builder integration tests are included. Finally, 200 distinct
SAT-generated simple pseudoline models, with seeded random solver phases,
and 200 random concurrent rational arrangements each retain an orbit member
satisfying the generated clauses and compatible breaks. SAT-generated models
are not claimed to be uniform samples or necessarily stretchable. Testing
supports, but does not replace, the proof above or independent review.
