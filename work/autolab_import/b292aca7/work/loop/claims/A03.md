# A03 — Corrected residue system for t >= 7

**Round-2 revision, proposed; not self-refereed.** This supersedes the original sketch at 840a1335 and applies the operator's referee corrections. Pairwise-intersecting setting, n=18, T>=94, no fourfold point. Use A01 notation B,beta,m,sigma,C,Z and n_i=#{points with i blocks}.

Necessary conditions:

- (R-a) **B+beta >= 3t-6+Z**, equivalently sum c(P)>=t-6+Z. Equality is not a threshold constraint: it would wrongly exclude T>=95.
- (R-b) beta<=sigma=3t-m.
- (R-c) B<=2t+C, B>=m+Z-6, m+Z<=2t+6+C.
- (R-d) n_2+2n_3>=B-t>=m+Z-6-t. This is a weighted count, not a count of distinct points when C>0.
- (R-e) beta>=t-6+Z-C; separately beta>=1 for t>=7 by C07's beta=0 exclusion.
- (R-f) For **axis points**, Lemma A gives a touch or a triple-bearing cap. Distinct such touches are bounded by 2Z. Do not extrapolate the axis touch argument to centroid points without justification.
- (R-g) sum j_L=3t, m<=18, j_L<=8; 3t<=binom(m,2). Parity C11 applies only when its non-cap and single-sided-entry hypotheses hold, not to every shared line.
- (R-h) c=b+e/2-2; axis c<=2, with bridges only in all-multiple faces; bent c in {1/2,1,2}, with the C07/C19 corrected restrictions; one-block c=e/2-1; blockless c=e/2-2; centroid c=5/2. **e>=3 for one-block and e>=5 for blockless are necessary only for c>0, never unconditional hard constraints.**

A02 gives geometric cap incidences. Its item 5 must not be added to per-point m-values already counting x.

**New reduction:** A04 strengthens the window to m+Z+ceil(C/2)<=2t+6, by counting interrupted gaps; it proposes exclusion of t=7,m=18, and lists surviving aggregate profiles. See A05 for a replacement exact encoding specification. The original claim of fewer than 200 aggregate cases was not justified and is withdrawn.

**SAT precautions.** Count each segment and bridge exactly once, using canonical endpoint representatives, with two-way definitions. A single block is two adjacent cap triangles, not the four triangles specifying two blocks. Keep only chi(0,1,2)!=-1 from the earlier symmetry breaks: do NOT import C32's line-0-off-triples constraint (false when m=18). Do not import C32's simple-endpoint unused-segment restriction; it was proved only for that specific five-point residue.

**Dependencies:** C34, C07/C19 verdict fixes, C10, A01/A02 as corrected by the operator. Neither C35 nor C38 is used: the full six-point case is not known closed here. A SAT model is only a combinatorial candidate, not a straight-line construction. No closure of all t=7 or t=8 is asserted.
