## 2. Return constraint system at a double-B star P
Variables: x = (U+, U+′, U−, U−′) ∈ {T, Q}^4, where T = triple and Q = quad. The returns are at least triples (Pin 5).

Constraints:
- M1: ¬(x2 = T ∧ x3 = T); M2: ¬(x1 = T ∧ x4 = T);
- Q1: x2 = Q → x4 = T; Q2: x4 = Q → x2 = T; Q3: x1 = Q → x3 = T; Q4: x3 = Q → x1 = T;
- S+: ¬(x1 = Q ∧ x2 = Q); S−: ¬(x3 = Q ∧ x4 = Q).

The system is unsatisfiable. Removing any single Q constraint leaves it unsatisfiable, because Q-violations come in
pairs.

The assignments violating exactly one constraint are:
- M1 only: TTTQ, QTTT, QTTQ;
- M2 only: TTQT, TQTT, TQQT;
- S− only: TTQQ;
- S+ only: QQTT.

**Every one of these has a quad return.** A quad return is a double-B star (three consecutive bridges plus the mask
classification), so it needs its own rescue. Hence a single hard defect must break the chains of two adjacent stars
at once. TTTT violates both M1 and M2, so it needs two defects.

## 3. Lemma R: every return of a double-B star is a triple (simplifies the star theorem)
Setting and notation as in STAR_CASES.md. The zero-corner facts needed are listed in §4.

**Far corners of a quad return.** Suppose U+ = D+∩γ−∩e1 is a quad, with fourth line d.
- Its bridges U+B+, U+A+, U+Y+ are consecutive, from the faces A+U+B+ and A+Y+U+. They are double by saturation, so
  U+ is double-B with its case-B axis d.
- Kite at B+: by the lemma at B+ (exterior face A+B+U+), the far corner is the vertex next to B+ on α+ away from A+,
  which is U−.
- Kite at Y+: by the lemma at Y+ (exterior face A+Y+U+), the far corner is the vertex next to Y+ on a away from A+,
  which is W2+ = a∩e2. Here we use that V+ is a triple with face V+Y+W2+, so W2+ is the first vertex on a beyond Y+.
- Far corners lie on the case-B axis, so U−, W2+ ∈ d.
- A case-B far corner is a triple, so U− = D−∩α+∩e4 is a triple. (This is Lemma Q.)

**Contradiction.**
- d passes through U−, so d ∈ {D−, α+, e4}.
- d also passes through U+ ∈ γ−. But D−∩γ− = C− ≠ U+ and α+∩γ− = B+ ≠ U+. Hence d = e4.
- So W2+ ∈ e4, giving W2+ = a∩e4 = W2−. These lie on a on opposite sides of P. Contradiction.

Symmetrically:
- U+′ quad gives d = e3 and W1+ = W1−;
- U− quad gives d = e1 and W1− = W1+;
- U−′ quad gives d = e2 and W2− = W2+.

**Corollary (short star theorem).** All returns are triples, so the first half of Lemma M (U+′ and U− both triples)
puts α+∩α− at both ends of α+. Contradiction. (STAGE2_TASK8 §7 and the second half of Lemma M are not needed.)

## 5. Cascade lemma (lead): with one Δ-event, Y+ (or Z+) cannot be simple
Case (e): one 2-token event in total. Suppose Y+ is simple. Then A+Y+ and T+Y+ are single, which is an O* event,
and that spends the whole budget.
- **At T+** (ring TA, TX, TF, −α+, −H, −φ+): T+Y+ is single, so (−φ+, TA) is a triangle (TAY) and (−H, −φ+) is not.
  T+Z+ is double, because T+F+Z+ is all-multiple: Z+ multiple, else a second O*. So (−α+, −H) is the face TZV.
  Since (−H, −φ+) is not a triangle, **TV is single**.
- **If V is multiple:** TZV is all-multiple with single edge TV. That is M*, a second event.
- **If V is simple (lines H and Z's third line):**
  - If ZV is single, then TZV is O*, a second event.
  - If ZV is double, the face across ZV from T has its third vertex on V's ray −H and on Z's ray −c. That vertex
    would be c∩H = P, which lies behind T, on the wrong ray.

Contradiction in every branch. Z+ simple is symmetric, and so are Y−, Z−. **PROVED.**
